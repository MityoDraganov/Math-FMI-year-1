# 05. Функции

## Понятие за функция

В математиката (най-общо) **функция** е съпоставяне на определени величини, наричани **аргументи**, на други величини, наричани **стойности**, като на дадени аргументи се съпоставя точно една стойност.

В езика C++ функциите са основен конструктивен елемент на програмите. Функцията получава аргументи и връща резултат (**върнат резултат**).

- Дават възможност за многократна употреба: всяка функция се състои от множество от оператори, оформени подходящо, за да се използват като обобщено действие или операция. След като една функция бъде дефинирана, тя може да бъде изпълнявана многократно за различни входни данни.
- **Разделяй и владей:** позволяват да се създават програми от комбиниране на по-малки елементи (т.е. функции). Всеки такъв елемент е по-ясен и лесен за тестване и модифициране.
- Избягва се многократното повтаряне на едни и същи програмни фрагменти. Те се дефинират еднократно като функции, след което могат да бъдат изпълнявани произволен брой пъти.
- В повечето случаи се постига икономия на памет, тъй като кодът на функцията се съхранява само на едно място в паметта, независимо от броя на нейните изпълнения.

## Дефиниране на функция в C++

```
<сигнатура> { <тяло> }
<сигнатура> ::= [ <тип_резултат> | void ] <идентификатор> ( <формални_параметри> )
<формални_параметри> ::= <без параметри> | void | <параметър> {, <параметър> }
<параметър> ::= <тип> [<идентификатор>]
<тяло> ::= { <оператор> }
```

`void` е празен тип: функцията не връща резултат.

## Извикване на функция

- Със стартиране на програмата се извиква главната функция `main()`.
- След това всяка функция, включително и `main()`, може да извиква произволен брой други функции.
- Извикването на функция е операция с много висок приоритет.
- Извикващата функция продължава изпълнението само след като извиканата функция завърши. Всяка функция завършва при срещане на `}`, която маркира края на тялото ѝ, или при изпълнение на оператора `return;`.

```
<име>(<фактически_параметри>)
<фактически_параметри> ::= <празно> | void | <израз> {, <израз> }
```

При извикването се извършва `<формален_параметър> = <фактически_параметър>`: типът на фактическия параметър се съпоставя с типа на съответния формален параметър и, ако се налага, се прави преобразуване на типовете. Фактическите параметри се наричат още **атрибути** (аргументи).

В дефиницията `long gcd(long a, long b) { ... }` `long` е типът, `gcd` е името, `long a, long b` са формалните параметри, а частта между `{` и `}` е тялото. В извикването `gcd(130, 50);` `gcd` е името на функцията, която извикваме, а `130, 50` са фактическите параметри (аргументи).

## Връщане на резултат

Една функция може и да не връща нищо:

```cpp
void PrintLine(unsigned int Size)
{
   for(int i=0; i < Size; i++)
   {
      cout << '-';
   }
}

int main()
{
   PrintLine(10); // OK
   int x = PrintLine(20); // Грешка!
}
```

Ако функцията има тип (например `int`), то всички пътища на изпълнение трябва да връщат стойност от този тип:

```cpp
int MyFunction(int a)
{
    if (a > 0)
    {
        // a is positive
        return a;
    }
    else
    {
        // a is negative
    }
}
```

Тук при `a <= 0` функцията завършва без `return` и върнатата стойност е недефинирана (компилаторът дава само предупреждение).

Операторът `return;` прекратява изпълнението на `void` функция. Ако `ReadPositiveIntFromFile()` е функция, която прочита положително число от някакъв файл и връща `-1`, ако не успее:

```cpp
void MyFunction()
{
    int Data = ReadPositiveIntFromFile();

    if (Data == -1)
    {
        cout << "ERROR: Cannot read from file!\n";
        return;
    }

    // Тук използваме прочетените стойности ...
}
```

## Дефиниция и декларация на функция

**Декларацията** на функцията представлява нейната сигнатура, последвана от `;`.
- Не е задължителна.
- Декларацията е своеобразно „обещание“ за дефиниране на функцията по-късно в кода на програмата.

**Дефиницията** на функцията описва и нейното тяло.

Декларацията на дадена функция задължително трябва да предшества извикването ѝ в друга функция.

```cpp
int f();
int g(int, int); // В декларацията можем да пропуснем
                 // имената на параметрите

int main()
{
    int a = f();
    int b = g(5, 10);
}

int f()
{
    return 10;
}

int g(int a, int b)
{
    return a + b * 100;
}
```

Без декларация функцията трябва да е дефинирана преди мястото на извикването:

```cpp
int f()                 // Дефиниция на f()
{
    return 10;
}

int main()
{
    int a = f();      // ОК: f() е дефинирана по-горе
    int b = g(5, 10); // Грешка! Не е ясно какво е g?
}

int g(int a, int b)     // Дефиниция на g()
{
    return a + b * 100;
}
```

Грешката се отстранява или като дефиницията на `g()` се премести преди `main()`, или като преди `main()` се поставят декларациите `int f();` и `int g(int a, int b);`. С декларации редът на дефинициите не е от значение; една функция може да извиква друга, декларирана по-горе, но дефинирана по-долу:

```cpp
int f();               // Декларация на f()
int g(int a, int b);   // Декларация на g()

int main()
{
    int a = f();       // ОК: функцията f() е декларирана по-горе
}

int f()                // Дефиниция на f()
{
    return g(10, 2);   // OK: функцията g() е декларирана по-горе
}

int g(int a, int b)    // Дефиниция на g()
{
    return a + b * 100;
}
```

## Област на видимост

Променлива, дефинирана в тялото на функция, е видима само в тази функция (от дефиницията си до края на тялото).

```cpp
void f()
{
    int b = 1000;   // област на видимост на b: тялото на f()
    a = 2000;       // Грешка!
}

int main()
{
    int a = 1;      // област на видимост на a: тялото на main()
    f();
    b = 2;          // Грешка!
    return 0;
}
```

Променлива, дефинирана извън всички функции (**глобална**), е видима във всички функции след нея. Програмата извежда `200`:

```cpp
#include <iostream>
using namespace std;

int c;

void f() {
    c = 200;
}

int main() {
    c = 100;
    f();
    cout << c << endl;
    return 0;
}
```

Локална променлива скрива глобална със същото име; до глобалната се достига с `::`:

```cpp
#include <iostream>
using namespace std;

int a = 0;

void f()
{
    int a = 10;
    cout << a << "-" << ::a << endl; // Извежда 10-0
}

int main()
{
    int a = 1000;
    f();
    cout << a << "-" << ::a << endl; // Извежда 1000-0
}
```

## Подаване на параметри

Характерно за параметрите на функциите:
- Пресмята се стойността на фактическия параметър.
- В специално място в паметта (наречено **стекова рамка** на функцията) се създава копие на стойността.
- След това всяка промяна на стойността остава локална за функцията.
- При завършване на функцията предадената стойност и всички промени над нея се загубват.

**Предаване на параметри по стойност:** функцията работи върху копие на оригиналните данни. Програмата извежда `1000`, после `0`:

```cpp
void f(int a)
{
    a = 1000;
    cout << a << endl;
}

int main()
{
    int a = 0;
    f(a);
    cout << a << endl;
    return 0;
}
```

За да може функцията да променя стойностите на аргументите си (например функция, която разменя стойностите на две числа), се използват типовете указател и псевдоним.

**Тип указател:**

```cpp
int a = 10;
int *pa;
```

**Тип псевдоним (reference):**

```cpp
int a;
int &ra = a;
```

**Предаване на аргументи по псевдоним:** формалният параметър е псевдоним на фактическия, т.е. функцията работи върху оригиналната променлива, а не върху копие.

## Предефиниране на функции

Няколко функции може да имат едно и също име, ако се различават по броя или вида на параметрите си (**предефиниране**, overload). При извикване се избира версията, чиито параметри съответстват на фактическите параметри.

```cpp
void MyFunction(int a)
{
    cout << "MyFunction (int)\n";
}

void MyFunction(double a)
{
    cout << "MyFunction (double)\n";
}

double MyFunction(int a, double b)
{
    cout << "MyFunction (int, double)\n";
    return (double)a * 10.0 + b;
}
```

```cpp
int a = 5;
double b = 10;

MyFunction(a);          // MyFunction(int)
MyFunction(b);          // MyFunction(double)
MyFunction(a, b);       // MyFunction(int, double)

MyFunction(10);         // MyFunction(int)

MyFunction(10.0);       // MyFunction(double)
MyFunction((double)10); // MyFunction(double)

MyFunction(10, 10.0);   // MyFunction(int, double)
MyFunction(10.0, 10);   // MyFunction(int, double), WARNING!
```

**Бел.** В слайдовете на последния ред е `// MyFunction(double), WARNING!`, трябва да е `MyFunction(int, double)`: единствената версия с два параметъра е `MyFunction(int, double)`; `10.0` се преобразува до `int`, а `10` до `double` (предупреждението е за загубата при `double` → `int`).

Функция **не може** да се предефинира само по типа на върнатия резултат. Трябва да има и разлика в броя или вида на аргументите.

```cpp
int MyFunction(int a)
{
    cout << "MyFunction(int)\n";
}
double MyFunction(int a)    // Грешка!
{
    cout << "MyFunction(double)\n";
}
int main()
{
    MyFunction(10); // Коя версия бихме извикали тук?
}
```

## Параметри по подразбиране

```cpp
int MyFunction(int a, int b = 0)
{
    return a + b;
}

int main()
{
    int x = MyFunction(10, 20); // x = 30;
    int y = MyFunction(10);     // y = 10;
    int z = MyFunction();       // Грешка!
}
```

Подразбиращите се параметри трябва винаги да бъдат в края:

```cpp
int MyFunction(int a = 0, int b) // Грешка!
{
    return a + b;
}
```

Предефиниране и параметри по подразбиране могат да доведат до нееднозначно извикване:

```cpp
int MyFunction(int a = 10, int b = 10)
{
    return a + b;
}

int MyFunction()
{
    return 0;
}

int main()
{
    int x = MyFunction(); // Грешка!
}
```

## Пример: генериране на таблицата за умножение

Програмата, генерираща таблица за умножение ([[04-03-Таблица-за-умножение]]), се подобрява, като кодът се разпределя във функции, всяка от които отговаря за различна задача.

**Премахване на „странни“ (магически) числа.** Числата `10` (размер на таблицата) и `4` (ширина на клетка) се заменят с именувани константи:

```cpp
// Въвеждаме константа за размер на таблицата
const int TABLE_SIZE = 10;
// Въвеждаме константа за размер на клетка в таблицата
const int FIELD_SIZE = 4;

// Извеждаме линията под числата
int LineLength = 3 + TABLE_SIZE * FIELD_SIZE;

for (int count = 1; count <= LineLength; count++)
    std::cout << '-';
```

Фиксираният размер на таблицата не е удобен: по-добре е потребителят да избере размера. При произволен размер фиксираната ширина от 4 позиции за числата също не върши работа, затова ширината на клетката се пресмята:

```
Ширина = Максимален размер на число + Отстъп между числата
```

```cpp
int MaxNumberLength =
    (int) log10((double)(TableSize * TableSize)) + 1;

const int FIELD_MARGIN = 2;

int FieldSize = MaxNumberLength + FIELD_MARGIN;
```

## Контрол на входните данни

Възможно е потребителят да въведе невалидна стойност (текст вместо число или число извън допустимия интервал). Въвеждането се повтаря, докато стойността стане валидна:

```cpp
int TableSize = 0;

do
{
    std::cout << "Enter table size: ";
    std::cin >> TableSize;
    if (cin.fail()) {
        cin.clear();
        cin.ignore(std::numeric_limits<std::streamsize>::max(), '\n');
        continue;
    }
} while (TableSize <= 1 || TableSize >= 12);
```

`cin.fail()` проверява дали последното въвеждане е неуспешно, `cin.clear()` изчиства състоянието на грешка, а `cin.ignore(...)` пропуска въведеното до края на реда (изисква `#include <limits>`). `continue` в `do`-`while` прехвърля изпълнението към проверката на условието.
