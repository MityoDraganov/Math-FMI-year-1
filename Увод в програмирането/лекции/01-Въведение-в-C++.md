# 01. Основи на езика C++

## Софтуер и хардуер

Софтуер и хардуер (на български: програмно осигуряване и апаратно осигуряване). Най-общо казано, за работата на компютъра е необходим следният софтуер:
- операционни системи;
- приложни програми.

За създаването на приложните програми са необходими и т.нар. интегрирани среди за разработка на софтуер (Integrated Development Environment, IDE).

Нивата, от най-ниското към най-високото: хардуер; операционна система; среди за разработка, виртуални машини и други; вашите програми.

## Операционни системи (ОС)

Всеки компютър работи под управлението на някаква ОС. Тя управлява програмите и:
- взаимодействието между потребителите и хардуера;
- периферните устройства (чрез драйвери);
- файловете (чрез файловата система).

Широкоразпространени ОС са MS DOS, MS WINDOWS, UNIX, LINUX, но също и Android, iOS и т.н.

## Как се създава една програма

Процесите, които включва създаването на една компютърна програма:
1. Писане на код.
2. Анализ на синтаксиса.
3. Анализ на семантиката.
4. Свързване и оптимизация на кода.
5. Генерация на изпълним код.
6. Оптимизация на изпълнимия код.

Освен това: проектиране; автоматично създаване на често употребяван код; отстраняване на грешки (debugging).

Примерен процес на създаване на програма: изходният код се обработва от компилатор и се получава обектен код; свързващата програма свързва обектния код с библиотеките и се получава изпълнима програма.

```
изходен код → компилатор → обектен код → свързваща програма → изпълнима програма
                                               ↑
                                          библиотеки
```

## Интегрирани среди за разработка (IDE)

Целта им е да улеснят процеса на програмиране и да автоматизират някои дейности от него. Интегрираните среди за разработка включват:
- език за програмиране;
- транслатор (компилатор или интерпретатор), свързващ редактор;
- изпълнителна система;
- система за проверка на програмите;
- система за поддържане на библиотеки;
- текстови редактори.

Популярни интегрирани среди за разработка: Visual Studio, Eclipse, Code Blocks.

## Какво представлява компютърът

Основни части: процесор, памет, входно устройство, изходно устройство.

Най-общо казано, компютърът е средство за представяне и обработване на информация. Компютърът е устройство или система, която може да изпълнява определена последователност от операции. Това са най-често числови изчисления, аналитични преобразувания или обработка на данни, но включват също и входно/изходни операции.

## Първа програма на C++

```cpp
#include <iostream>

using namespace std;

int main()
{
    cout << "Hello world!";

    return 0;
}
```

Части на програмата:
- заглавни (header) файлове;
- функция `main()`:
  - инструкции;
  - оператор `return`.

## Структура на програмата на C++

```
<изходен_файл> ::=
          <заглавен_блок_с_коментари>
          <заглавни_файлове>
          <константи>
          <глобални_променливи>
          <класове>
          <функции>
```

**Заглавни (header) файлове.** Съдържат декларации, които се използват в повече от една част на програмата. Действат като интерфейс между различните компилируеми части на програмата (библиотеки, други програми).

## Азбука на езика C++

- Главните и малките букви на латинската азбука.
- Цифрите.
- Специалните символи `+ - * / = ( ) [ ] { } | : ; " ' < > , . _ ! @ # $ % ^ ~`

## Идентификатор

**Дефиниция.** Идентификатор е наименование на елемент в програмата. Той е поредица от символи: букви, цифри и знака за долна черта. Може да започва само със символа `$`, буква или долна черта.

Валидни идентификатори: `abc`, `ABC`, `minValue1`, `_first_setting`, `$tree`.

Невалидни идентификатори: `1ba`, `ab+1`, `a(1)`.

**Бел.** В слайдовете `$` е посочен като позволен символ. Стандартът на C++ не го допуска в идентификатори; GCC и Clang го приемат като разширение на компилатора.

### Лоши практики за имена на идентификатори

```cpp
int $php = 5;
double _$_ = 3;
char nayqkiqsimvolever = 'M';
float MnOgOqKo = 2.4;
bool _ = false;
long __ = 5234;
long long $$ = 42342;
unsigned gjnueirgeri = 453;
```

### Добри практики за имена на идентификатори

- Имената трябва да обясняват ролята на съответния идентификатор.
- Не е добре да са много дълги.
- Не е препоръчително да са на български с латински букви: кодът може да се чете от колега, който не знае езика.
- Има различни препоръки за именоване на идентификатори, т.нар. конвенции (naming conventions).

Сравнение: `b = b - a` срещу `balance = balance - withdrawn_amount` и `balance = balance - withdrawnAmount`. Вторият и третият запис са по-ясни.

```cpp
// Конвенции за именуване на променливите

// Много, много лош стил:
int abfd_77 = x - y998;

// Много по-ясно:
int MonthlyProfit = Income - Expenses;

int nMonthlyProfit = fpIncome - fpExpenses;
```

Също добри практики:

```cpp
int age = 5;
double sum = 3;
char coolestSymbol = 'M';
float MyDegree = 5.6;
long remaning_slides = 5234;
bool isOk = true;
bool hasBlueEyes = false;
```

## Ключови думи

**Дефиниция.** Ключови думи са вградени в езика идентификатори, които се използват в програмите по стандартен, предварително определен начин.

- Ключови думи на C++: `int`, `namespace`, `return` и т.н.
- Ключови думи на препроцесора: `include`, `undef`, `ifdef` и т.н.
- Ключови думи на компилатора: зависят от конкретния компилатор.

## Коментари

**Дефиниция.** Коментарът е произволен текст, ограден със знаците `/*` и `*/` или от `//` и EOL (знак за край на реда).

```
<коментар> ::= /* <редица_от_знаци> */ |
               // <редица_от_знаци> Край на реда
```

Коментарът пояснява програмен фрагмент. Предназначен е за програмиста и се игнорира от компилатора на езика.

Хубаво е всеки файл да започва със заглавен блок с коментари, даващи информация за целта му, за използваните компилатор и операционна система, за името на програмиста и датата на създаването на файла. Писането на коментари значително повишава качеството на кода.

Коментарите от C (`/* ... */`) може да са на няколко реда и да се появят навсякъде, включително в средата на ред. Въпреки че е възможно, това не трябва да се прави в собствения код.

```cpp
/* Това е класическият тип коментар от C */
int x;

int /* …и да се появи навсякъде */ z;
```

Коментарите в стил C++ (`//`) завършват в края на реда. Ако трябва да са на няколко реда, всеки ред се коментира поотделно.

```cpp
// Тези коментари завършват в края на реда
int x;

// Ако искате да са на няколко реда
// ще трябва да коментирате всеки от
// тях поотделно.
int y;
```

По правило коментарите (независимо от стила) се поставят или над това, което коментират, или вдясно от него.

```cpp
int z; // …или вдясно от него.
```

## Променливи

**Дефиниция.** Променлива е част от паметта за съхранение на данни, която може да съдържа различни стойности по време на изпълнение на програмата.

Променливите имат три характеристики: тип, име, стойност. Името на променливата трябва да е валиден идентификатор. Всяка променлива трябва да има тип, който се указва при дефинирането ѝ.

### Дефиниране на променливи

```
<име_на_тип> <променлива> [= <израз>]опц
            {, <променлива> [= <израз>]опц}опц;
```

където `<име_на_тип>` е дума, означаваща име на типа на променливата, а `<израз>` е правило за получаване на стойност (цяла, реална, знакова и друг тип), съвместимо с името на типа на променливата.

```cpp
int i = -123, j = 33;

char a = 's';
char b = 115;

double value;

string add;
```

## Основни типове данни

- Скаларни:
  - булев (`bool`);
  - символен (`char`);
  - целочислен (`int`);
  - за числа с плаваща запетая (`float`, `double`).
- Съставни типове:
  - масив (`T[]`), в частност символен низ (`char []`);
  - структура (`struct`).

Още типове: през втората половина на семестъра.

### Булев (логически) тип: `bool`

Множеството от стойности се състои от два елемента: стойностите `true` (1) и `false` (0).

```
<булева_константа> ::= true | false
```

Основни логически операции ([[Логика - импликация, квантори, отрицание]]):
- `&&`: AND;
- `||`: OR;
- `!`: NOT.

### Символен тип: `char`

Променливите от тип `char` са с размер 1 байт. Множество от стойности: $[-128; 127]$; за `unsigned char`: $[0; 255]$.

Литерали:
- `'<символ>'`;
- `'\<контролен_символ>'`, например `'\n'` (нов ред), `'\t'` (табулация) и др.

### Целочислени типове

| Тип | Множество от стойности |
|---|---|
| `short` | $[-2^{15}; 2^{15}-1]$ |
| `int` | $[-2^{31}; 2^{31}-1]$ |
| `long` | $[-2^{63}; 2^{63}-1]$ |
| `long long` | $[-2^{63}; 2^{63}-1]$ |
| `unsigned short` | $[0; 2^{16}-1]$ |
| `unsigned int` | $[0; 2^{32}-1]$ |
| `unsigned long` | $[0; 2^{64}-1]$ |

Числа без знак: `unsigned`.

**Бел.** Обхватът на `long` зависи от платформата: стандартът гарантира поне 32 бита. Под Linux и macOS (64-битови) `long` е 64-битов, както е в слайдовете, но под Windows (Visual Studio) `long` и `unsigned long` са 32-битови, т.е. $[-2^{31}; 2^{31}-1]$ и $[0; 2^{32}-1]$.

### Операции с целочислени типове

Аритметични операции:
- едноместни операции за знак (`+`, `-`);
- двуместни аритметични операции:
  - `a + b` (събиране);
  - `a - b` (изваждане);
  - `a * b` (умножение);
  - `a / b` (целочислено деление, частно);
  - `a % b` (деление по модул, остатък; [[Делимост и остатъци]]).

Операции за сравнение (предикати):
- `a == b` (равно);
- `a != b` (различно);
- `a < b` (по-малко);
- `a > b` (по-голямо);
- `a <= b` (по-малко или равно);
- `a >= b` (по-голямо или равно).

### Едноместни операции с целочислени типове

- `++`: събиране с 1;
- `--`: изваждане с 1.

Префиксни операции: `--a`, `++a`. Постфиксни операции: `a--`, `a++`.

Пример 2: [[01-02-Префиксни-и-постфиксни-операции]]

**Забележка.** Повишената употреба на префиксните и постфиксните операции често води до трудно четим код.

## Числа с плаваща запетая

В компютъра няма безкрайно количество памет, с която да се представят всички реални числа. Затова се говори за дробни числа, или още числа с плаваща запетая:
- тип `float`;
- тип `double`.

### Операции с числа с плаваща запетая

- Валидни са всички операции за целочислените типове, без делението по модул.
- Резултатът от операцията `/` е дробно деление, а не частно.
- Максималното число: за `float` е $\approx 3{,}40282 \cdot 10^{38}$, за `double` е $\approx 1{,}79769 \cdot 10^{308}$.
- Трябва да се има предвид точността на представянето на реалните числа при сравняването им. Машинна нула.

За да няма загуба на информация, се препоръчва преобразуване на типовете в следната посока:
- `bool` → `char` → `short` → `int` → `long` → `float` → `double`;
- `unsigned char` → `unsigned short` → `unsigned int` → `unsigned long`.

## Константи

```
const <име_на_тип> <име_на_константа> = <израз>;
```

Добра практика е често повтарящите се стойности да се дефинират като константи, които след това да се използват в програмата. Конвенцията за именуване на константите е те да се записват само с главни букви.

```cpp
const int MAXINT = 32767;
const double RI = 2.5 * MAXINT;
const double PI = 3.14159265;
```

Предимства:
- програмите стават по-ясни и четливи;
- стойностите им лесно (само на едно място) се променят, ако се налага;
- намалява възможността за грешки при многократното изписване на стойността на константата.

## Литерал

**Дефиниция.** Литерал е константна стойност на променлива, зададена в кода.

```cpp
int i = 2;
char c = 'a';
bool isReal = true;

int i = 023;      // число в осмична бройна система
int i = 0x1F;     // число в шестнадесетична бройна система
int i = 0b100011; // число в двоична бройна система
```

**Бел.** В слайдовете последният ред е `Int I = 0b100011`, без `;`; трябва да е `int` (C++ различава главни и малки букви). Записът `0b...` е допустим от C++14 нататък.

## Statement (инструкция)

Инструкциите са команди в дадена компютърна програма, които се изпълняват в определена последователност. Включват един или повече оператори. В C++ има няколко вида оператори.

## Оператор за присвояване на стойност

```
<променлива> = <израз>;
```

където `<променлива>` е идентификатор, дефиниран вече като променлива, а `<израз>` е израз от тип, съвместим с типа на `<променлива>`.

```
<lvalue> = <rvalue>
```

- `<lvalue>`: място в паметта със стойност, която може да се променя (например променлива).
- `<rvalue>`: временна стойност, без специално място в паметта (например константа, литерал, резултат от пресмятане).

### Съкратени оператори за присвояване

`+=`, `-=`, `*=`, `/=`:

```cpp
a += 4;  // Еквивалентно на a = a + 4;
a *= 22; // Еквивалентно на a = a * 22;
```

По-общо, `e1 op= e2;` е еквивалентно на `e1 = (e1) op (e2);`, където `op` е някой от операторите `+`, `-`, `*`, `/`, `%`, `<<`, `>>`, `&`, `|`, `^`.

### Едноместни операции и lvalue

`++a` и `--a` връщат `a`, което е lvalue. `a++` и `a--` връщат rvalue.

```cpp
--a += 22; // валиден израз
a-- += 22; // невалиден израз
```

## Асоциативност на операторите

Операторът за присвояване е дясноасоциативен: `a = b = 2` се изпълнява като `a = (b = 2)` (`<lvalue> = <rvalue>`).

Освен дясно-, се различават и лявоасоциативни оператори. Например аритметичните оператори са лявоасоциативни:

```cpp
double a = 16 / 2 / 2; // (16 / 2) / 2 = 4
```

## Приоритет на операторите

Приоритетът на операторите определя реда, в който те се прилагат в рамките на дадения израз. Таблицата е по низходящ приоритет (съкратена версия).

| Оператор | Име | Асоциативност |
|---|---|---|
| `++` | Postfix Increment | Left to Right |
| `--` | Postfix Decrement | Left to Right |
| `++` | Prefix Increment | Right to Left |
| `--` | Prefix Decrement | Right to Left |
| `*` | Multiplication | Left to Right |
| `/` | Division | Left to Right |
| `%` | Modulus | Left to Right |
| `+` | Addition | Left to Right |
| `-` | Subtraction | Left to Right |
| `<` | Less Than | Left to Right |
| `>` | Greater Than | Left to Right |
| `&&` | Logical And | Left to Right |
| `\|\|` | Logical Or | Left to Right |
| `?:` | Conditional | Right to Left |
| `=` | Assignment | Right to Left |
| `,` | Comma | Left to Right |

**Бел.** В слайдовете `%` е в групата на `+` и `-`; трябва да е в групата на `*` и `/` (същият приоритет като умножение и деление). Например `7 + 10 % 3` е $7 + 1 = 8$.

```cpp
bool isTrue = 30 < 7 + 32/8; // 30 < (7 + (32/8)), т.е. 30 < 11: false
```

## Оператор за изброяване

```
<израз1>, <израз2>, ..., <изразN>
```

Оценяват се всички изрази отляво надясно (лявоасоциативен). Стойността на оператора се определя от най-десния израз. Използва се рядко.

```cpp
int a = 0;

1+2, a, a+10;   // Стойност на израза: 10

a++, a++, a++;  // Стойност на израза: 2
                // Стойност на a: 3
```

## Празен оператор

Знакът `;`. Не извършва никакви действия. Използва се, когато синтаксисът на някакъв оператор изисква присъствието на поне един оператор, а логиката на програмата не изисква такъв.

## Съставен оператор (блок)

Синтаксис:

```
{<оператор1>
 <оператор2>
  ...
 <операторN>
}
```

Семантика:
- Обединява нула или повече оператора в един. Може да бъде поставен навсякъде, където по синтаксис стои оператор.
- Дефинициите в рамките на блока се отнасят само за него, т.е. не могат да се използват извън него.
- Самият блок не завършва с `;`.

## Области на видимост на променливите

Нарича се още „област на действие“ (scope).
- Областта на действие се простира от дефиницията на променливата до края на блока, в който е дефинирана.
- Дефиниция на променлива със същото име в същия блок е забранена.
- Дефиницията на променлива във вложен блок припокрива всички дефиниции със същото име във външните блокове.

Пример 5: [[01-05-Област-на-видимост-на-променливите]]

```cpp
int Variable = 100;

if (Variable > 0)
{
    int Local = 100;
}

cout << "Variable = " << Variable << endl; // ОК
cout << "Local = " << Local << endl;       // Грешка!
```

## Оператор за вход: `>>`

```
cin >> <променлива> {>> <променлива>};
```

където
- `cin` е обект (променлива) от клас (тип) `istream`, свързан с клавиатурата;
- `<променлива>` е идентификатор, дефиниран като променлива от „допустим тип“ преди оператора за въвеждане (типовете `int`, `long`, `double` са допустими).

Операторът извлича (въвежда) от `cin` (клавиатурата) поредната дума и я прехвърля в аргумента-приемник `<променлива>`.

Изразът `cin >> <променлива1> >> <променлива2> >> … >> <променливаn>;` е еквивалентен на

```
cin >> <променлива1>;
cin >> <променлива2>;
…
cin >> <променливаn>;
```

## Оператор за изход: `<<`

```
cout << <израз> {<< <израз>};
```

където
- `cout` е обект (променлива) от клас (тип) `ostream`, свързан с екрана на компютъра;
- `<израз>` е израз от допустим тип. Представата за израз продължава да бъде тази от математиката. Допустими типове са `bool`, `int`, `short`, `long`, `double`, `float` и др.

Операторът `<<` изпраща (извежда) към (върху) `cout` (екрана на компютъра) стойността на `<израз>`.

Изразът `cout << <израз1> << <израз2> << … << <изразn>;` е еквивалентен на

```
cout << <израз1>;
cout << <израз2>;
…
cout << <изразn>;
```
