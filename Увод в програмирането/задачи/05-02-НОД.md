# Най-голям общ делител (gcd)

**Условие.** Да се напише функция `long gcd(long a, long b)`, която връща най-големия общ делител на `a` и `b`.

**Какво се иска (с думи).** Най-големият общ делител (НОД) на две цели числа е най-голямото положително число, на което и двете се делят без остатък. Например НОД на `130` и `50` е `10`, а НОД на `12` и `18` е `6`. Функцията получава две числа от тип `long` и връща техния НОД; извикването `gcd(130, 50)` трябва да върне `10`.

*Решение.* Използва се, че при $a > b > 0$ числата $a$ и $b$ имат същите общи делители като $a - b$ и $b$. Затова по-голямото число се заменя с разликата, докато двете станат равни; тогава всяко от тях е НОД.

```cpp
long gcd(long a, long b)
{
    while (a != b)
    {
        if (a > b)
            a = a - b;
        else
            b = b - a;
    }

    return a;
}
```

Например `gcd(130, 50)`: $(130, 50) \to (80, 50) \to (30, 50) \to (30, 20) \to (10, 20) \to (10, 10)$, връща `10`.

Тази версия работи само за положителни `a` и `b`: при `0` или отрицателно число цикълът не завършва. Подобрената версия използва функцията `AbsoluteValue` ([[05-01-Абсолютна-стойност]]):

```cpp
long gcd(long a, long b)
{
    if (a == 0 || b == 0)
       return AbsoluteValue(a-b);
    if ( a < 0 ) a = AbsoluteValue(a);
    if ( b < 0 ) b = AbsoluteValue(b);

    while (a != b)
    {
        if (a > b)
            a = a - b;
        else
            b = b - a;
    }

    return a;
}
```

Ако едно от числата е `0`, НОД е абсолютната стойност на другото, т.е. $|a - b|$. Отрицателните числа се заменят с абсолютните им стойности (НОД не зависи от знака), след което се прилага същият цикъл. Например `gcd(0, -7)` връща `7`, а `gcd(-12, 18)` връща `6`.
