# Сума на списък от числа

**Условие.** Да се намери сумата на числата от даден списък и да се изведе дали тя е положителна („it is positive“) или нула или по-малка („it is zero or less“). Алгоритъмът да се запише на псевдокод и на програмен език (C++).

**Какво се иска (с думи).** Дадени са няколко числа, например 8, 3, 5, 11, 9, 2. Трябва да се съберат всички и да се провери резултатът: ако сборът е по-голям от нула, програмата отпечатва „it is positive“, иначе отпечатва „it is zero or less“. Едно и също решение трябва да се запише два пъти: веднъж на псевдокод (стъпки с думи, близки до програма) и веднъж като истинска програма на C++.

*Решение.* **Псевдокод.**

```
set total to zero

get list of numbers

loop through each number in the list
    add each number to total
end loop

if number more than zero
    print "it's positive" message
else
    print "it's zero or less" message
end if
```

**Бел.** В слайдовете е „if number more than zero“, трябва да е „if total more than zero“: проверява се сумата, а не отделно число.

**Програмен език (C++).** Сумата се пази в `sum`, числата са в масива `numbers`, а `i` е индексът на текущото число. Цикълът `while` минава през шестте елемента и добавя всеки към `sum`; след това `if`/`else` извежда съобщението.

```cpp
#include <iostream>

using namespace std;

int main()
{
    int sum = 0;
    int numbers[] = { 8,3,5,11,9,2 };

    int i = 0;
    while (i < 6)
    {
        sum += numbers[i];
        i++;
    }

    if (sum>0)
        cout << "it is positive" << endl;
    else
        cout << "it is zero or less" << endl;

    return 0;
}
```

Трите основни алгоритмични концепции: последователност от действия (`int sum = 0;`, `int i = 0;`), повторение (`while (i < 6)`), разклонение (`if (sum>0) ... else ...`).

**Отговор.** За числата $8, 3, 5, 11, 9, 2$ сумата е $38 > 0$ и програмата извежда `it is positive`.
