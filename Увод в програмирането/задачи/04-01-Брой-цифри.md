# Намиране на броя цифри на дадено число

**Условие.** Да се въвеждат цели числа и за всяко да се извежда броят на цифрите му. Въвеждането приключва с 0. Задачата да се реши с `do...while` и с `while`.

**Какво се иска (с думи).** Програмата пита потребителя за цяло число, различно от нула, например 2026, и отговаря `2026 has 4 digits`. След това пита отново и така, докато потребителят не въведе 0: тогава програмата спира. Знакът не се брои, т.е. за -305 отговорът е 3 цифри. Едно и също поведение трябва да се постигне с два различни оператора за цикъл.

*Решение.* Броят на цифрите на $n \neq 0$ е $\lfloor \log_{10}|n| \rfloor + 1$: в програмата това е `(int)log10((double)abs(Value)) + 1` (`log10` от `<cmath>`, `abs` от `<cstdlib>`).

**Вариант с do...while.**
```cpp
int main()
{
    int Value = 0;

    do {
        cout << "Enter a non-zero integer or 0 to quit: ";
        cin >> Value;

        cout << Value << " has "
             << (int)log10((double)abs(Value)) + 1
             << " digits" << endl << endl;

    } while (Value != 0);

    return 0;
}
```

**Бел.** В този вариант при въведена 0 условието се проверява едва след извеждането, така че програмата извежда ред и за 0, преди да спре. Тогава `log10(0)` е $-\infty$ и преобразуването към `int` е недефинирано поведение (с g++ се получава `0 has -2147483647 digits`). Това е причината за въпроса „?“ в слайдовете и за следващите два варианта.

**Вариант с while.** Четенето се прави веднъж преди цикъла и веднъж в края на тялото; условието `Value != 0` се проверява преди извеждането.
```cpp
int main()
{
    int Value = 0;

    cout << "Enter a non-zero integer or 0 to quit: ";
    cin >> Value;

    while (Value != 0)
    {
        cout << Value << " has "
             << (int)log10((double)abs(Value)) + 1
             << " digits" << endl << endl;

        cout << "Enter a non-zero integer or 0 to quit: ";
        cin >> Value;
    }

    return 0;
}
```

**Вариант с do...while и break.** Цикълът е безкраен (`while (true)`), а излизането става с `break` веднага след въвеждане на 0.
```cpp
int main()
{
    int Value = 0;

    do {
        cout << "Enter a non-zero integer or 0 to quit: ";
        cin >> Value;

        if (Value == 0) break;

        cout << Value << " has "
             << (int)log10((double)abs(Value)) + 1
             << " digits" << endl << endl;

    } while (true);

    return 0;
}
```

**Бел.** В слайдовете в последните два варианта е `" has"`, трябва да е `" has "`: иначе се извежда `2026 has4 digits`. Във варианта с `while` след затварящата скоба на цикъла има излишно `;` (`};`), което е празен оператор и не променя резултата.
