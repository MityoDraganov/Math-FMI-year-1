# Размяна на стойностите на две числа (swap)

**Условие.** Да се напише функция, която разменя стойностите на две числа.

**Какво се иска (с думи).** Ако в `main()` имаме `a = 5` и `b = 8`, след извикването на функцията с `a` и `b` трябва да е `a = 8` и `b = 5`. Функцията трябва да промени самите променливи от `main()`, а не техни копия.

*Решение.* При предаване по стойност функцията работи върху копия и размяната не се отразява в `main()`. Затова параметрите са от тип псевдоним `int&`: `x` и `y` са други имена на `a` и `b`.

```cpp
void swap(int& x, int& y) {
  int tmp = x;
  x = y;
  y = tmp;
}

int main() {
  int a = 5, b = 8;
  swap(a, b);
  cout << a << ' ' << b << endl;
}
```

Старата стойност на `x` се запазва в `tmp`, в `x` се записва `y`, а в `y` се записва запазената стойност. Програмата извежда `8 5`.
