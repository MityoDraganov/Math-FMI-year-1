# Вариант 21, зад. 3: switch към if

*Контролно 1, 2025/26 (`материали/UP_2025-26_Kontrolno_1.pdf`)*

**Условие.** Напишете еквивалентен код на програмния фрагмент, като използвате само оператор(и) `if` и/или `if-else`, без да използвате оператор `switch`. Обосновете написания от вас код.
```cpp
switch (s) {
    case 0:
    case 1:
    case 2: cout << "simple"; break;
    case 3:
    case 4: cout << "ops ";
    case 5: cout << "five"; break;
}
```

**Какво се иска (с думи).** Трябва да се напише код с `if`, който печата същото за всяко `s`. Изпълнението на `switch` започва от съвпадащия `case` и продължава надолу до `break` (т.нар. пропадане, fall-through). Трябва да се види какво печата всяка стойност 0, 1, …, 5 и какво става при други стойности (няма `default`).

> [!note]- Решение
> Какво печата `switch`:
> - `s` = 0, 1, 2: пропада до `case 2`, печата `simple`, `break`.
> - `s` = 3, 4: печата `ops `, няма `break`, пропада в `case 5`, печата `five`. Общо `ops five`.
> - `s` = 5: печата `five`.
> - друго: нищо (няма `default`).
>
> ```cpp
> if (s == 0 || s == 1 || s == 2)
>     cout << "simple";
> else if (s == 3 || s == 4)
>     cout << "ops five";
> else if (s == 5)
>     cout << "five";
> ```
> Еквивалентно, като се запази пропадането: `if (s == 3 || s == 4) cout << "ops "; if (s >= 3 && s <= 5) cout << "five";` (при цяло `s`).
