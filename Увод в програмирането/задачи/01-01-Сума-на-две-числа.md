# Втора програма на C++: сума на две числа

**Условие.** Програма, която въвежда от клавиатурата две цели числа `a` и `b` и извежда сумата им.

**Какво се иска (с думи).** Програмата трябва да покаже на екрана подкана „Input a: “, да прочете число, после „Input b: “ и второ число, и накрая да отпечата изречение със сумата на двете. Например при въведени 221 и 33 на екрана трябва да излезе `The sum of a and b is: 254`.

*Решение.*

```cpp
#include <iostream>

using namespace std;

int main()
{
    int a = 0, b = 0;

    cout << "Input a: "; cin >> a;
    cout << "Input b: "; cin >> b;
    cout << "The sum of a and b is: " << a + b
         << endl << "\n";

    return 0;
}
```

Двете променливи `a` и `b` са от тип `int` и се инициализират с 0 в една дефиниция. Всеки ред с `cout << "..."; cin >> ...;` съдържа два оператора: извеждане на подкана и въвеждане на стойност. В последния `cout` изразът `a + b` се пресмята и стойността му се извежда; `endl` и `"\n"` извеждат два знака за нов ред.

Изход при вход 221 и 33:

```
Input a: 221
Input b: 33
The sum of a and b is: 254
```
