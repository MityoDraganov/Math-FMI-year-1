# Област на видимост на променливите

**Условие.** Какво извежда програмата?

```cpp
int main()
{
    int a = -1;
    int b = 2;

    {
        int a = ++b * 3;
        int b = 12;

        cout << "Inner a and b: " << a
             << " and " << b << endl;
    }

    cout << "Outer a and b: " << a
         << " and " << b << endl;
}
```

**Какво се иска (с думи).** В `main` има променливи `a` и `b`, а във вътрешния блок `{ ... }` се дефинират нови променливи със същите имена. Трябва да се определи кои `a` и `b` се използват на всеки ред и какви стойности се отпечатват вътре в блока и след него.

*Решение.*

```cpp
#include <iostream>
using namespace std;

int main()
{
    int a = -1;
    int b = 2;

    {
        int a = ++b * 3;
        int b = 12;

        cout << "Inner a and b: " << a
             << " and " << b << endl;
    }

    cout << "Outer a and b: " << a
         << " and " << b << endl;
}
```

1. Външните променливи: `a = -1`, `b = 2`.
2. Във вътрешния блок се дефинира ново `a`. В инициализиращия израз `++b * 3` вътрешно `b` още не е дефинирано, затова `b` е външното: `++b` го увеличава на 3 и вътрешното `a` става $3 \cdot 3 = 9$.
3. Дефинира се вътрешно `b = 12`; то припокрива външното `b` до края на блока.
4. Вътре се извеждат 9 и 12.
5. След края на блока вътрешните `a` и `b` вече не съществуват. Външното `a` не е променяно (-1), а външното `b` е 3 заради `++b`.

Изход:

```
Inner a and b: 9 and 12
Outer a and b: -1 and 3
```
