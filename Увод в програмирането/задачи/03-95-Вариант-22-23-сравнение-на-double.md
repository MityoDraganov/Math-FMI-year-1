# Варианти 22 и 23, зад. 2: подобрения (сравнение на double)

*Контролно 1, 2025/26 (`материали/UP_2025-26_Kontrolno_1.pdf`)*

**Условие.** Разгледайте кода. Можете ли да направите някакви подобрения по него? Какви? Обяснете какъв е смисълът им и защо са необходими те според вас.
```cpp
double num1, num2;
cin >> num1 >> num2;
if (num1 == num2)
    cout << "Only " << num1 * 4.12;
else
    cout << num1 * 4.12 << "; " << num2 * 4.12 << endl;
```

**Какво се иска (с думи).** Кодът работи, но е написан лошо. Трябва да се изброят конкретните проблеми (кое е опасно, кое се повтаря, кое е неясно) и за всеки да се каже как се поправя и защо.

> [!note]- Решение
> 1. **Сравнение на `double` с `==`.** Реалните числа се пазят приблизително (напр. `0.1 + 0.2 == 0.3` е невярно). Сравнява се с точност: `fabs(num1 - num2) < EPS`, с `const double EPS = 1e-9;` и `#include <cmath>`.
> 2. **„Магическо число“ `4.12`.** Повтаря се три пъти и не е ясно какво значи. Става именувана константа: `const double FACTOR = 4.12;`. Промяната е на едно място.
> 3. **Повторено пресмятане.** `num1 * 4.12` се смята в двата клона. Изчислява се веднъж в променлива.
> 4. **Липсва `endl` в първия клон.** Изходът е непоследователен.
> 5. **Няма покана за вход и проверка дали четенето е успешно** (`if (!(cin >> num1 >> num2))`).
> 6. Фигурни скоби и при едноредови клонове, за четимост и за да не се получи грешка при добавяне на ред.
>
> ```cpp
> const double FACTOR = 4.12, EPS = 1e-9;
> double num1, num2;
> cout << "Въведете две числа: ";
> cin >> num1 >> num2;
> double r1 = num1 * FACTOR;
> if (fabs(num1 - num2) < EPS) {
>     cout << "Only " << r1 << endl;
> } else {
>     cout << r1 << "; " << num2 * FACTOR << endl;
> }
> ```
