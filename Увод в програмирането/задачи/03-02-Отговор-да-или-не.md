# Разпознаване на отговор „Yes“ / „No“ със switch

**Условие.** Въвежда се символ. Да се отпечата дали потребителят е въвел „Yes“ (`y`), „No“ (`n`) или нещо друго.

**Какво се иска (с думи).** Програмата прочита един символ (`char`). Ако той е `y`, трябва да се отпечата, че потребителят е отговорил „Yes“; ако е `n`, че е отговорил „No“; при всеки друг символ (например `x` или `7`), че е въвел нещо друго. За всеки вход трябва да се отпечата точно един ред.

*Решение.* Изборът е по стойността на един израз (`Input`) спрямо константи, затова се използва `switch`.
```cpp
cout << "Enter a character: ";
char Input;
cin >> Input;

switch (Input)
{
case 'y':
    cout << "The user entered \"Yes\".\n";
    break;

case 'n':
    cout << "The user entered \"No\".\n";
    break;

default:
    cout << "The user entered something else.\n";
}
```
`break` прекратява изпълнението на `switch`. Без операторите `break` при вход `y` изпълнението продължава в следващите case-изрази и се отпечатват и трите реда; при вход `n` се отпечатват последните два.

Ако се приемат и главните букви `Y` и `N`, към всеки случай се добавя втори `case` етикет без оператори между тях:
```cpp
cout << "Enter a character: ";
char Input;
cin >> Input;
switch (Input)
{
case 'y':
case 'Y':
    cout << "The user entered \"Yes\".\n";
    break;
case 'n':
case 'N':
    cout << "The user entered \"No\".\n";
    break;
default:
    cout << "The user entered something else.\n";
}
```
