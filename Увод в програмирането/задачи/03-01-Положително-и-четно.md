# Проверка дали дадено число е положително и четно

**Условие.** Проверка дали дадено число е положително и четно.

**Какво се иска (с думи).** Програмата прочита от клавиатурата едно цяло число `num`. Трябва да се провери дали то е едновременно по-голямо от $0$ и четно (дели се на $2$ без остатък, [[Делимост и остатъци]]). Например $6$ е положително и четно, $61$ е положително, но нечетно, а $-4$ е четно, но не е положително.

*Решение.* Двете изисквания се съединяват с `&&`. Числото е четно точно когато остатъкът при деление на $2$ е $0$, т.е. `0 == num % 2`.

Вариант с `if`: съобщение се отпечатва само ако условието е изпълнено.
```cpp
int main()
{
    int num = 0;
    cin >> num;

    if ((num > 0) && (0 == num % 2))
        cout << "Number is OK!\n";

    return 0;
}
```
При вход `6` се отпечатва `Number is OK!`; при вход `61` не се отпечатва нищо.

Вариант с `if/else`: и в двата случая се отпечатва съобщение.
```cpp
int main()
{
    int num = 0;
    cin >> num;

    if ((num > 0) && (0 == num % 2))
        cout << "Number is OK!\n";
    else
        cout << "Number is not OK!\n";

    return 0;
}
```
При вход `61` се отпечатва `Number is not OK!`.
