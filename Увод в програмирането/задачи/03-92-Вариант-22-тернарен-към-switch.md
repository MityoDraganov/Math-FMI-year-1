# Вариант 22, зад. 3: тернарен оператор към switch

*Контролно 1, 2025/26 (`материали/UP_2025-26_Kontrolno_1.pdf`)*

**Условие.** Напишете еквивалентен код на следния програмен фрагмент, като използвате само оператор(и) `switch`, без да използвате оператор `if` и тернарен оператор:
```cpp
int x,r;
cin >> x;
(x == 2 || x == 7) ? r = 1 : ( x == 8 ? r=0 : r=-1);;;
cout << r;
```

**Какво се иска (с думи).** Трябва да се разбере каква стойност получава `r` за всяко `x` и да се напише същото със `switch`. Тернарният оператор `условие ? А : Б` изпълнява А, ако условието е вярно, иначе Б; тук е вложен. `;;;` в края трябва да се обясни.

> [!note]- Решение
> Разчитане: ако `x` е 2 или 7, `r = 1`; иначе, ако `x` е 8, `r = 0`; иначе `r = -1`. Двете допълнителни `;` са празни оператори и не правят нищо.
>
> ```cpp
> int x, r;
> cin >> x;
> switch (x) {
>     case 2:
>     case 7:  r = 1;  break;
>     case 8:  r = 0;  break;
>     default: r = -1;
> }
> cout << r;
> ```
> `case 2:` без `break` пропада в `case 7:`, което реализира „или“.
