# Таблица за умножение с функции

**Условие.** Да се подобри програмата, генерираща таблица за умножение ([[04-03-Таблица-за-умножение]]), като кодът се разпредели във функции, всяка от които отговаря за различна задача. Размерът на таблицата и отстъпът между числата се въвеждат от потребителя.

**Какво се иска (с думи).** Програмата пита за размер на таблицата (от 1 до 12) и за отстъп между числата (от 1 до 3). След това извежда таблица с толкова реда и стълба: на ред $i$ и стълб $j$ стои $i \cdot j$, отляво е номерът на реда и `|`, отгоре е заглавен ред с числата и линия от тирета. Всяка клетка е толкова широка, колкото е най-голямото число в таблицата плюс отстъпа. Например при размер `5` и отстъп `2` най-голямото число е `25` (2 цифри), значи клетката е широка 4 позиции.

*Решение.* Използват се функциите `NumberSize` ([[05-04-Брой-цифри]]) и `PromptForInteger` ([[05-05-Въвеждане-в-интервал]]), както и две помощни функции.

Извеждане на линия:

```cpp
void PrintLine(int Length)
{
    for (int i = 0; i < Length; i++)
        std::cout << '-';

    std::cout << std::endl;
}
```

Заглавният ред и редовете на таблицата се извеждат с почти един и същ код: заглавният ред е като ред с множител `1`.

```cpp
for (int number = 1; number <= 10; number++)
    std::cout << std::setw(4) << (1 * number);

for (int rhs = 1; rhs <= 10; rhs++)
    std::cout << std::setw(4) << (lhs * rhs);
```

Затова и двата се извеждат от една функция. Извеждане на един ред:

```cpp
void PrintNumbers(int Start, int End,
                  int Factor, int FieldSize)
{
    for (int i = Start; i <= End; i++)
        std::cout << std::setw(FieldSize) << (i * Factor);

    std::cout << std::endl;
}
```

Цялата таблица:

```cpp
void PrintTable(int TableSize, int FieldMargin)
{
    int FieldSize = NumberSize(TableSize * TableSize) + FieldMargin;

    std::cout << "The multiplication table:\n\n";

    // Извеждаме заглавния ред
    std::cout << " #|";
    PrintNumbers(1, TableSize, 1, FieldSize);
    PrintLine(3 + TableSize * FieldSize);

    // Извеждаме таблицата
    for (int row = 1; row <= TableSize; row++)
    {
        std::cout << std::setw(2) << row << '|';
        PrintNumbers(1, TableSize, row, FieldSize);
    }

    std::cout << std::endl;
}
```

Най-голямото число в таблицата е `TableSize * TableSize`, затова ширината на клетка е броят на цифрите му плюс отстъпа. Дължината на линията е `3` (за `" #|"`, съответно за номера на реда и `|`) плюс `TableSize` клетки по `FieldSize` позиции.

Окончателен вид на `main()`:

```cpp
int main()
{
    int TableSize = PromptForInteger("Table Size", 1, 12);

    int FieldMargin = PromptForInteger("Field Margin", 1, 3);

    PrintTable(TableSize, FieldMargin);

    return 0;
}
```

Програмата изисква `#include <iostream>`, `#include <iomanip>` (за `std::setw`) и, ако `NumberSize` е с `log10`, `#include <cmath>`; функциите трябва да са дефинирани (или декларирани) преди `main()`. При размер `5` и отстъп `2` се извежда:

```
The multiplication table:

 #|   1   2   3   4   5
-----------------------
 1|   1   2   3   4   5
 2|   2   4   6   8  10
 3|   3   6   9  12  15
 4|   4   8  12  16  20
 5|   5  10  15  20  25
```
