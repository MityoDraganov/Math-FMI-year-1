# Вариант 24, зад. 1: while с вложен do-while

*Контролно 1, 2025/26 (`материали/UP_2025-26_Kontrolno_1.pdf`)*

**Условие.** Опишете последователно какво ще изведе на екрана следният програмен фрагмент. Обосновете отговора си.
```cpp
int i = 0;
while ( ++i, ++i < 15)
    do
    {
        cout << i * 2 << endl;
    } while (i++ < 6);
```

**Какво се иска (с думи).** Трябва да се изпише какво печата кодът. Тялото на `while` е цял `do-while` цикъл. Условието на `while` съдържа оператора запетая: изпълняват се и двата израза, а за условие се използва само последният (`++i < 15`).

> [!note]- Решение
> Операторът запетая: `(++i, ++i < 15)` увеличава `i` два пъти и проверява новата стойност. `do-while` изпълнява тялото поне веднъж; `i++ < 6` сравнява старото `i` и после го увеличава.
>
> 1. `while`: `i` 0 → 1 → 2, `2 < 15` е вярно.
>    `do-while`: печата 4; `2 < 6`, `i`=3; печата 6; `3 < 6`, `i`=4; печата 8; `i`=5; печата 10; `5 < 6`, `i`=6; печата 12; `6 < 6` е невярно, `i`=7.
> 2. `while`: `i` 7 → 8 → 9, `9 < 15` е вярно. Печата 18; `9 < 6` е невярно, `i`=10.
> 3. `while`: `i` 10 → 11 → 12, `12 < 15` е вярно. Печата 24; невярно, `i`=13.
> 4. `while`: `i` 13 → 14 → 15, `15 < 15` е невярно. Край.
>
> **Отговор.** 4, 6, 8, 10, 12, 18, 24, всяко на нов ред.
