# Вариант 24, зад. 3: три независими if към switch

*Контролно 1, 2025/26 (`материали/UP_2025-26_Kontrolno_1.pdf`)*

**Условие.** Напишете еквивалентен код на следния програмен фрагмент, като използвате само оператор(и) `switch`:
```cpp
if (a == 10) cout << "xyz";
if ( (a == 4) || (a == 6) ) cout << "this!";
if ( (a >= 6) && (a <= 8) ) cout << "correct";
```

**Какво се иска (с думи).** Трябва да се напише код със `switch`, който печата същото. Трите `if` са независими (без `else`), затова при някои стойности на `a` може да се отпечатат два текста. Трябва да се намери какво печата всяка стойност.

> [!note]- Решение
> Таблица (за цяло `a`):
> - 10: `xyz`
> - 4: `this!`
> - 6: `this!correct` (и второто, и третото условие са верни)
> - 7, 8: `correct`
> - друго: нищо.
>
> ```cpp
> switch (a) {
>     case 10: cout << "xyz"; break;
>     case 4:  cout << "this!"; break;
>     case 6:  cout << "this!";   // без break: пропада към correct
>     case 7:
>     case 8:  cout << "correct"; break;
> }
> ```
> Пропадането от `case 6` в `case 7/8` дава точно `this!correct`.
>
> **Бел.** Типът на `a` не е даден. `switch` работи само с цели типове (и `char`), затова приемаме `int a`.
