# if към switch: one, 13, big, error

*Примерни задачи за първото контролно (страница в Moodle)*

**Условие.** Напишете еквивалентен код на следния програмен фрагмент, като използвате оператор `switch` (и не използвате `if`):
```cpp
int a;
if (a == 1)
    cout << "one";
if (a != 3)
    cout << "13";
else if (a > 3)
    cout << "big";
else
    cout << "error";
```

**Какво се иска (с думи).** Трябва да се напише код само със `switch`, който при всяка стойност на `a` печата точно същото като дадения. Първо трябва да се разбере какво печата оригиналът за всяко `a`: двата `if` са независими (първият няма `else`).

> [!note]- Решение
> **Бел.** В условието `a` не е инициализирана. Приемаме, че стойността ѝ е въведена (`cin >> a;`).
>
> Анализ на оригинала:
> - `a == 1`: първият `if` печата `one`; `a != 3` е вярно, печата `13`. Общо `one13`.
> - `a == 3`: първият не печата; `a != 3` е невярно, `a > 3` е невярно, печата `error`.
> - всяко друго `a`: печата `13`.
>
> Клонът `big` никога не се изпълнява: стигаме до `else if` само когато `a == 3`, а тогава `a > 3` е невярно.
>
> ```cpp
> switch (a) {
>     case 1:  cout << "one" << "13"; break;
>     case 3:  cout << "error"; break;
>     default: cout << "13";
> }
> ```
