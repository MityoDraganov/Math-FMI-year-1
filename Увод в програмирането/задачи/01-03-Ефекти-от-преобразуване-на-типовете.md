# Ефекти от преобразуване на типовете

**Условие.** Какви стойности получават `A`, `B`, `C` и `D` в програмата?

```cpp
float A = 5 / 9;
float B = 5.0 / 9.0;
float C = 5.0 / 9;
float D = 5 / 9.0;
```

**Какво се иска (с думи).** И четирите променливи са дробни (`float`) и навсякъде се дели 5 на 9. Разликата е само в това дали числата са записани като цели (`5`, `9`) или като дробни (`5.0`, `9.0`). Трябва да се определи какво ще отпечата програмата за всяка от четирите.

*Решение.*

```cpp
#include <iostream>
using namespace std;

int main()
{
    float A = 5 / 9;
    float B = 5.0 / 9.0;
    float C = 5.0 / 9;
    float D = 5 / 9.0;

    cout << "A = " << A << endl
         << "B = " << B << endl
         << "C = " << C << endl
         << "D = " << D << endl;

    return 0;
}
```

- `5 / 9`: двата операнда са `int`, затова `/` е целочислено деление и резултатът е частното 0. Едва след това 0 се преобразува във `float`: `A = 0`.
- `5.0 / 9.0`: двата операнда са `double`, делението е дробно: `B = 0.555556`.
- `5.0 / 9` и `5 / 9.0`: единият операнд е `double`, другият (`int`) се преобразува към `double` и делението е дробно: `C = D = 0.555556`.

Изход:

```
A = 0
B = 0.555556
C = 0.555556
D = 0.555556
```
