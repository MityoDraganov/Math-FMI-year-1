# Варианти 21 и 24, зад. 2: глобални променливи и foo1

*Контролно 1, 2025/26 (`материали/UP_2025-26_Kontrolno_1.pdf`)*

**Условие.** Разгледайте кода. Опишете какви подобрения може да направите в него. Обосновете ги. Какво ще бъде изведено на стандартния изход след изпълнението на този код?
```cpp
int a = 12;
int c = -5;

int foo1() {
    return -a*++c;
}

int main() {
    int b = 2;
    std::cout << foo1()+b*b << std::endl;
}
```

**Какво се иска (с думи).** Трябва (1) да се пресметне какво печата програмата и (2) да се изброят подобренията. `a` и `c` са глобални (обявени извън функциите), а `foo1` не приема параметри и променя `c`.

> [!note]- Решение
> **Изход.** `++c`: `c` става −4 и това е стойността. `-a * (-4) = -12 * (-4) = 48`. В `main`: `48 + 2*2 = 52`. Извежда се `52`.
>
> **Подобрения.**
> 1. **Без глобални променливи.** `foo1` зависи от скрито състояние и го променя (страничен ефект: `c` остава −4, второ извикване дава друг резултат). Данните се подават като параметри: `int foo1(int a, int c) { return -a * (c + 1); }`.
> 2. **Без `++` в израз.** `-a*++c` е труден за четене; `c + 1` или отделен ред `++c;` е по-ясно.
> 3. **Смислени имена** вместо `foo1`, `a`, `b`, `c`.
> 4. **Константи** с `const`, ако стойностите не се променят.
> 5. `return 0;` в края на `main` (не е задължително, но е прието), коментари какво пресмята функцията.
>
> ```cpp
> int compute(int a, int c) {
>     return -a * (c + 1);
> }
>
> int main() {
>     const int A = 12, C = -5, B = 2;
>     std::cout << compute(A, C) + B * B << std::endl;   // 52
>     return 0;
> }
> ```
