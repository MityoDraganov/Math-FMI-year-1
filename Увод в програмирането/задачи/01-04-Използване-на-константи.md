# Използване на константи

**Условие.** Програма, която въвежда три числа `a`, `b`, `c` и извежда всяко от тях, умножено с един и същ множител 4.55, зададен като константа.

**Какво се иска (с думи).** Потребителят въвежда три дробни числа. За всяко от тях програмата отпечатва произведението му с 4.55. Например при въведени 1, 2, 10 се отпечатват 4.55, 9.1 и 45.5. Множителят трябва да е записан само на едно място в програмата.

*Решение.*

```cpp
#include <iostream>
using namespace std;

int main()
{
    float a, b, c;
    const float MULTIPLIER = 4.55;

    cout << "Input a "; cin >> a;
    cout << "Input b "; cin >> b;
    cout << "Input c "; cin >> c;

    cout << "First value is "  << a*MULTIPLIER << endl;
    cout << "Second value is " << b*MULTIPLIER << endl;
    cout << "Third value is "  << c*MULTIPLIER << endl;
}
```

Множителят е дефиниран веднъж като константа `MULTIPLIER` (с главни букви, по конвенцията за константи). Ако стойността трябва да се смени, това става само на едно място, а не в трите израза.

**Забележка.** В слайда редовете `#include <iostream>` и `using namespace std;` не са показани.
