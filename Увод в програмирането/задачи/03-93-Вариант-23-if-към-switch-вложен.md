# Вариант 23, зад. 3: if към вложен switch

*Контролно 1, 2025/26 (`материали/UP_2025-26_Kontrolno_1.pdf`)*

**Условие.** Напишете еквивалентен код на програмния фрагмент, като използвате само оператор(и) `switch`, без да използвате оператори `if` и/или тернарен оператор:
```cpp
if (x == 5 && y == 4) {
    cout << "OK";
}
else if (x == 4) {
    cout << x;
}
else {
    cout <<"not ok";
}
```

**Какво се иска (с думи).** Трябва да се напише същото поведение само със `switch`. Трудността е, че първото условие зависи от две променливи (`x` и `y`), а един `switch` проверява само една стойност. Трябва да се внимава какво печата оригиналът при `x == 5`, но `y != 4`.

> [!note]- Решение
> Условието с две променливи се реализира с `switch` по `y`, вложен в `case 5` на `switch` по `x`. Ако `x == 5` и `y != 4`, оригиналът стига до последния `else` (`x == 4` също е невярно) и печата `not ok`.
>
> ```cpp
> switch (x) {
>     case 5:
>         switch (y) {
>             case 4:  cout << "OK"; break;
>             default: cout << "not ok";
>         }
>         break;
>     case 4:  cout << x; break;
>     default: cout << "not ok";
> }
> ```
> `break` след вложения `switch` е задължителен: без него `case 5` пропада в `case 4` и печата и `x`.
