# Въвеждане на число в даден интервал

**Условие.** Да се напише функция, която въвежда от потребителя цяло число в интервала от `LowerLimit` до `UpperLimit` и го връща.

**Какво се иска (с думи).** Функцията получава долна и горна граница. Тя пита потребителя за число и, ако то е извън границите, пита отново, докато не бъде въведено число между тях (включително границите). Например при граници `1` и `12` отговорите `-5` и `100` се отхвърлят, а `5` се приема и се връща.

*Решение.*

```cpp
// Въвеждане на число в даден интервал
int PromptForInteger(int LowerLimit, int UpperLimit)
{
    int Input = 0;

    do
    {
        std::cout << "Enter an integer between "
                  << LowerLimit << " and "
                  << UpperLimit << ": ";
        std::cin >> Input;

    } while (Input < LowerLimit ||
             Input > UpperLimit);

    return Input;
}
```

```cpp
int main()
{
    int TableSize = PromptForInteger(1, 12);
    int FieldMargin = PromptForInteger(1, 3);

    // Това е най-голямото число, което ще се
    // появи в таблицата.
    int MaxNumber = TableSize * TableSize;

    int FieldSize = NumberSize(MaxNumber) +
        FieldMargin;
    ...
```

При изпълнение се извежда `Enter an integer between 1 and 12:` и `Enter an integer between 1 and 3:`, без да е ясно какво точно се въвежда. Затова се добавя параметър с името на въвежданата величина:

```cpp
int PromptForInteger(const char* Name, int LowerLimit, int UpperLimit)
{
    int Input;

    do
    {
        std::cout << "Enter " << Name
                  << " (between " << LowerLimit
                  << " and " << UpperLimit << "): ";

        std::cin >> Input;

    } while (Input < LowerLimit ||
             Input > UpperLimit);

    return Input;
}
```

```cpp
int main()
{
    int TableSize = PromptForInteger("Table Size", 1, 12);
    int FieldMargin = PromptForInteger("Field Margin", 1, 3);
    ...
```

Сега се извежда `Enter Table Size (between 1 and 12):` и `Enter Field Margin (between 1 and 3):`.

**Бел.** Във функцията от слайдовете няма проверка `cin.fail()`. Ако се въведе текст (например `abc`), `cin` остава в състояние на грешка, `Input` става `0` и цикълът не завършва никога. За пълен контрол на входа в тялото на цикъла трябва да се добави проверката с `cin.clear()` и `cin.ignore(...)` от лекцията.
