# Абсолютна стойност на цяло число

**Условие.** Да се намери абсолютната стойност на дадено цяло число.

**Какво се иска (с думи).** Трябва да се напише функция, която получава едно цяло число и връща неговата абсолютна стойност ([[Модул (абсолютна стойност)]]): числото без знака минус. Например за `7` резултатът е `7`, за `-7` е `7`, за `0` е `0`. В `main()` потребителят въвежда число, функцията се извиква с него и резултатът се извежда.

*Решение.*

```cpp
int AbsoluteValue(int number) {
   int retValue;
   retValue = (number >= 0) ? number : -number;
   return retValue;
}
```

Функцията има един формален параметър `number` от тип `int` и връща резултат от тип `int`. Условният оператор `?:` избира `number`, ако `number >= 0`, и `-number` в противен случай.

Извикване на функцията:

```cpp
int main() {
  int aNumber;
  cout << "Input a number: "; cin >> aNumber;
  aNumber = AbsoluteValue(aNumber);
  cout << "The absolute value is: " << aNumber << endl;
}
```

**Алтернативи.** Резултатът може да се върне директно, без помощна променлива, а извикването може да участва като израз в извеждането:

```cpp
int AbsoluteValue(int number) {
   return (number >= 0) ? number : -number;
}

int main() {
   int aNumber;
   cout << "Input a number: "; cin >> aNumber;
   cout << "The absolute value is: " << AbsoluteValue(aNumber) << endl;
}
```
