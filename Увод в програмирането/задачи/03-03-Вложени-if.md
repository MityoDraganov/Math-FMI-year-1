# Вложени условни оператори: какъв ще бъде резултатът

**Условие.** Какъв ще бъде резултатът от изпълнението?
```cpp
int main()
{
    int a = 1;
    int b = 0;

    if (a > 0)
        if (b > 0)
            cout << "First  if" << endl;
    else
        cout << "Second if" << endl;

    return 0;
}
```
Същият въпрос за варианта с фигурни скоби около вътрешния `if`:
```cpp
int main()
{
    int a = 1;
    int b = 0;

    if (a > 0) {
        if (b > 0)
            cout << "First  if" << endl;
    }
    else
        cout << "Second if" << endl;

    return 0;
}
```

**Какво се иска (с думи).** Дадени са две почти еднакви програми с $a = 1$ и $b = 0$; разликата е само в чифта `{ }`. За всяка трябва да се каже какво ще се отпечата на екрана (може и нищо). Въпросът е към кой от двата `if` принадлежи `else`: подравняването на кода не е от значение за компилатора.

*Решение.* В първата програма `else` се свързва с най-близкия `if` без `else`, т.е. с `if (b > 0)`, въпреки отместването. Програмата е еквивалентна на
```cpp
if (a > 0) {
    if (b > 0)
        cout << "First  if" << endl;
    else
        cout << "Second if" << endl;
}
```
„First if“ се отпечатва при `(a>0) && (b>0)`, „Second if“ при `(a>0) && (b<=0)`. При $a = 1$, $b = 0$ се отпечатва `Second if`.

Във втората програма вътрешният `if` е затворен в блок, затова `else` се свързва с `if (a > 0)`. „First if“ се отпечатва при `(a>0) && (b>0)`, „Second if“ при `a <= 0`. При $a = 1$, $b = 0$ условието `a > 0` е `true`, а `b > 0` е `false`, затова не се отпечатва нищо.

Същото разклоняване може да се запише без влагане с логическа операция:
```cpp
int main()
{
    int a = 1;
    int b = 0;

    if (a > 0 && b > 0)
        cout << "first" << endl;
    else
        cout << "second" << endl;

    return 0;
}
```
Тук „first“ се отпечатва при `(a>0) && (b>0)`, а „second“ при отрицанието му `(a<=0) || (b<=0)`. При $a = 1$, $b = 0$ се отпечатва `second`.

**Отговор.** Първата програма отпечатва `Second if`; втората не отпечатва нищо; третата отпечатва `second`.
