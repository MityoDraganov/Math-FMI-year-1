# Брой цифри в запис на число

**Условие.** Да се напише функция `int NumberSize(int Number)`, която връща броя на цифрите в записа на числото `Number`.

**Какво се иска (с думи).** Функцията получава цяло число и връща колко цифри има то (знакът минус не се брои). Например за `7` резултатът е `1`, за `144` е `3`, за `-25` е `2`, за `0` е `1`. В таблицата за умножение това е ширината на най-голямото число.

*Решение.* Първи начин, чрез десетичен логаритъм (изисква `#include <cmath>`). За $n \geq 1$ броят на цифрите е $\lfloor \log_{10} n \rfloor + 1$:

```cpp
int NumberSize(int Number)
{
    int Absolute = (Number >= 0) ?
        Number :
        -Number;

    return (int)log10((double)Absolute) + 1;
}
```

**Бел.** В слайдовете тази версия не разглежда `Number == 0`: тогава `log10(0)` е $-\infty$ и преобразуването до `int` не дава `1` (с g++ резултатът е голямо отрицателно число). Трябва отделна проверка за `0`.

Често една и съща функционалност може да се имплементира по различни начини. Втори начин, с деление на `10`:

```cpp
int NumberSize(int Number)
{
    int Size = 1;
    int Current = (Number >= 0) ? Number : -Number;

    while (Current > 9)
    {
        Current = Current / 10;
        Size++;
    }

    return Size;
}
```

Докато числото има поне две цифри (`Current > 9`), последната цифра се премахва с целочислено деление на `10` и броячът се увеличава. Например за `144`: `144 → 14 → 1`, `Size = 3`. За `0` цикълът не се изпълнява и резултатът е `1`.
