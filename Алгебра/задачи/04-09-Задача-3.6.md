# Задача 3.6 (гр. 1)

**Условие.** Нека $F$ е поле. Докажете, че ако $C \in M_n(F)$ комутира с всички матрици от $M_n(F)$, то $C = \lambda E_n$ за $\lambda \in F$.

**Какво се иска (с думи).** „$C$ комутира с $X$“ означава $CX = XC$. Дадено е, че квадратната матрица $C$ от ред $n$ удовлетворява $CX = XC$ за **всяка** квадратна матрица $X$ от ред $n$. Трябва да се докаже, че тогава $C$ е число по единичната матрица, т.е. има едно и също число $\lambda$ навсякъде по главния диагонал и нули извън него. Например при $n = 2$: $C = \begin{pmatrix} \lambda & 0 \\ 0 & \lambda \end{pmatrix}$. Такива матрици се наричат **скаларни**.

*Решение.* Ще използваме многократно предната задача ([[04-08-Задача-3.5]]): $E_{pq}E_{rs} = \delta_{qr}E_{ps}$. Нека $C = (c_{ij})_{n\times n}$ е матрица от условието (тоест комутира с всички останали квадратни матрици от ред $n$). Тогава $C = \sum_{i,j=1}^{n} c_{ij}E_{ij}$ ([[Знак за сума и произведение]]).

*Елементите извън главния диагонал са нули.* Нека $1 \leq p \neq q \leq n$. Понеже $C$ комутира с $E_{pp}$,
$$E_{pp}CE_{qq} = CE_{pp}E_{qq} = C \cdot 0_{n\times n} = 0_{n\times n}.$$
От друга страна, $E_{pp}E_{ij} = \delta_{pi}E_{pj}$ е ненулево само при $i = p$, а $E_{pj}E_{qq} = \delta_{jq}E_{pq}$ е ненулево само при $j = q$, следователно
$$E_{pp}CE_{qq} = E_{pp}\Big(\sum_{i,j=1}^{n} c_{ij}E_{ij}\Big)E_{qq} = \Big(\sum_{j=1}^{n} c_{pj}E_{pp}E_{pj}\Big)E_{qq} = \Big(\sum_{j=1}^{n} c_{pj}E_{pj}\Big)E_{qq} = \sum_{j=1}^{n} c_{pj}E_{pj}E_{qq} = c_{pq}E_{pq}.$$
Оттук $c_{pq}E_{pq} = 0_{n\times n}$, т.е. $c_{pq} = 0$. Значи извън главния диагонал на матрицата $C$ имаме нули. Следователно $C = c_{11}E_{11} + c_{22}E_{22} + \dots + c_{nn}E_{nn}$.

*Елементите по главния диагонал са равни.* Нека $1 \leq k \leq n$. От една страна, понеже $C$ комутира с $E_{1k}$,
$$E_{1k}CE_{k1} = CE_{1k}E_{k1} = CE_{11} = (c_{11}E_{11} + c_{22}E_{22} + \dots + c_{nn}E_{nn})E_{11} = c_{11}E_{11}.$$
От друга страна, $E_{1k}E_{ii} = \delta_{ki}E_{1i}$ е ненулево само при $i = k$, следователно
$$E_{1k}CE_{k1} = E_{1k}(c_{11}E_{11} + c_{22}E_{22} + \dots + c_{nn}E_{nn})E_{k1} = (c_{kk}E_{1k}E_{kk})E_{k1} = c_{kk}E_{1k}E_{k1} = c_{kk}E_{11}.$$
Така за всяко $1 \leq k \leq n$ имаме $c_{kk} = c_{11}$. С $\lambda := c_{11}$ получаваме $C = \lambda(E_{11} + \dots + E_{nn}) = \lambda E_n$, т.е. $C$ е скаларна матрица. $\square$

**Забележка.** Обратното също е вярно: $\lambda E_n$ комутира с всяка $X \in M_n(F)$, защото $(\lambda E_n)X = \lambda X = X(\lambda E_n)$.

**Отговор.** Матриците, които комутират с всички матрици от $M_n(F)$, са точно скаларните матрици $\lambda E_n$, $\lambda \in F$.
