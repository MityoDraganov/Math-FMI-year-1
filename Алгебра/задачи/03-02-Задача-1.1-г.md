# Задача 1.1 г) (гр. 1)

**Условие.** Всички решения на $\sqrt{2i}$.

**Какво се иска (с думи).** $\sqrt{2i}$ тук не е едно число, а всички комплексни числа $w$, за които $w^2 = 2i$ (както и $2$, и $-2$ имат квадрат $4$). $i$ е имагинерната единица, $i^2 = -1$. Трябва да се намерят всички такива $w$ и да се запишат в алгебричен вид $a + bi$ с реални $a$ и $b$.

*Решение.* Използваме формулата на Моавър за $n$-ти корен. Тригонометричният вид на $i$ е $\cos\frac\pi2 + i\sin\frac\pi2$, следователно
$$\sqrt{2i} = \sqrt{2\left(\cos\frac\pi2 + i\sin\frac\pi2\right)} = \sqrt2\left(\cos\frac{\frac\pi2 + 2k\pi}{2} + i\sin\frac{\frac\pi2 + 2k\pi}{2}\right), \qquad k = 0, 1.$$
Получаваме две решения:
$$k = 0:\ \sqrt2\left(\cos\frac\pi4 + i\sin\frac\pi4\right) = \sqrt2\left(\frac{1}{\sqrt2} + \frac{1}{\sqrt2}i\right) = 1 + i;$$
$$k = 1:\ \sqrt2\left(\cos\frac{5\pi}{4} + i\sin\frac{5\pi}{4}\right) = \sqrt2\left(-\frac{1}{\sqrt2} - \frac{1}{\sqrt2}i\right) = -1 - i.$$
Решенията са $\pm(1 + i)$.
