# Задача 1.1 б) (гр. 1)

**Условие.** Да се запише в алгебричен вид
$$\frac{(1 + 2i)^2 - (2 - i)^3}{(1 - i)^3 + (2 + i)^2}.$$

**Какво се иска (с думи).** $i$ е имагинерната единица: $i^2 = -1$. Дробта има числител $(1 + 2i)^2 - (2 - i)^3$ и знаменател $(1 - i)^3 + (2 + i)^2$; степените $^2$ и $^3$ означават, че скобата се умножава по себе си два или три пъти. Трябва да се пресметне целият израз и да се запише в алгебричен вид $a + bi$ с реални $a$ и $b$, например $4 - 7i$. В отговора не трябва да остава дроб с $i$ в знаменателя.

*Решение.* ([[Съкратено умножение и изнасяне пред скоби]])
$$\frac{(1 + 2i)^2 - (2 - i)^3}{(1 - i)^3 + (2 + i)^2} = \frac{1 + 4i + (2i)^2 - (8 - 12i + 6i^2 - i^3)}{1 - 3i + 3i^2 - i^3 + 4 + 4i + i^2} = \frac{1 + 4i - 4 - 8 + 12i + 6 - i}{1 - 3i - 3 + i + 4 + 4i - 1} = \frac{-5 + 15i}{1 + 2i}.$$

**Бел.** В записките знаменателят е $1 + 3i + 3i^2 - i^3 + \dots$, трябва да е $1 - 3i + 3i^2 - i^3 + \dots$ (следващият ред е верен).

Умножаваме по комплексно спрегнатото на знаменателя:
$$\frac{-5 + 15i}{1 + 2i} = \frac{(-5 + 15i)(1 - 2i)}{(1 + 2i)(1 - 2i)} = \frac{-5 + 30 + 10i + 15i}{1 + 4} = \frac{25 + 25i}{5} = 5 + 5i.$$
