# $(1 + i)^{2026}$ (Лекция 2)

**Условие.** $(1 + i)^{2026} = ?$

**Какво се иска (с думи).** Трябва да се пресметне числото $1 + i$, умножено само по себе си 2026 пъти, и резултатът да се запише като едно комплексно число $x + iy$. Разкриването на скобите по Нютоновия бином е непрактично; затова числото първо се записва в тригонометричен вид $r(\cos\varphi + i\sin\varphi)$ и после се степенува.

*Решение.* $1 + i = r(\cos\varphi + i\sin\varphi)$, където
$$x = r\cos\varphi = 1, \quad y = r\sin\varphi = 1, \quad r = \sqrt2 \iff \cos\varphi = \frac{1}{\sqrt2}, \quad \sin\varphi = \frac{1}{\sqrt2},$$
т.е. $1 + i = \sqrt2\left(\cos\frac\pi4 + i\sin\frac\pi4\right)$. По формулата на Моавър
$$(1 + i)^{2026} = (\sqrt2)^{2026}\left(\cos\frac{2026\pi}{4} + i\sin\frac{2026\pi}{4}\right) = 2^{1013}\left(\cos\frac{2\pi}{4} + i\sin\frac{2\pi}{4}\right) = 2^{1013}\, i,$$
защото
$$\frac{2026\pi}{4} = \frac{2024}{4}\pi + \frac{2\pi}{4} = 506\pi + \frac\pi2 = 2 \cdot 253\pi + \frac\pi2$$
и $\cos(\varphi_0 + 2k\pi) = \cos\varphi_0$, $\sin(\varphi_0 + 2k\pi) = \sin\varphi_0$.

**Отговор.** $(1 + i)^{2026} = 2^{1013}\, i$.
