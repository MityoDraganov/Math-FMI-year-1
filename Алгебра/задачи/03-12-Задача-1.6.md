# Задача 1.6 (гр. 1)

**Условие.** За $x \notin 2\pi\mathbb{Z}$ да се докаже, че
$$\cos x + \cos(2x) + \dots + \cos(nx) = \frac{\sin\frac{nx}{2}\cos\frac{(n+1)x}{2}}{\sin\frac x2}, \qquad \sin x + \sin(2x) + \dots + \sin(nx) = \frac{\sin\frac{nx}{2}\sin\frac{(n+1)x}{2}}{\sin\frac x2}.$$

**Какво се иска (с думи).** $x$ е реално число (ъгъл), а $x \notin 2\pi\mathbb{Z}$ значи, че $x$ не е от вида $2k\pi$ с цяло $k$ (не е $0$, $\pm 2\pi$, $\pm 4\pi$, …); тогава $\sin\frac x2 \neq 0$ и дробите имат смисъл. Отляво стоят сумите на $n$ косинуса $\cos x, \cos(2x), \dots, \cos(nx)$ и съответно на $n$ синуса, а отдясно са готови формули за тях. Трябва да се докажат двете равенства за всяко $n$. Например при $n = 1$ първото гласи $\cos x = \frac{\sin\frac x2\cos x}{\sin\frac x2}$, което е вярно.

*Решение.* Нека $z := \cos x + i\sin x$. От формулите на Моавър $z^m = \cos(mx) + i\sin(mx)$. Нека
$$S_1 := \cos x + \cos(2x) + \dots + \cos(nx), \qquad S_2 := \sin x + \sin(2x) + \dots + \sin(nx).$$
Тогава (сума на геометрична прогресия с частно $z \neq 1$, [[Геометрична прогресия]])
$$S_1 + iS_2 = z + z^2 + \dots + z^n = z\,\frac{z^n - 1}{z - 1}.$$
Освен това ([[Тригонометрия (единична окръжност и формули)]])
$$z - 1 = (\cos x - 1) + i\sin x = -2\sin^2\frac x2 + 2i\sin\frac x2\cos\frac x2 = 2\sin\frac x2\left[\cos\left(\frac x2 + \frac\pi2\right) + i\sin\left(\frac x2 + \frac\pi2\right)\right].$$
С напълно аналогични разсъждения
$$z^n - 1 = 2\sin\frac{nx}{2}\left[\cos\left(\frac{nx}{2} + \frac\pi2\right) + i\sin\left(\frac{nx}{2} + \frac\pi2\right)\right].$$
Като заместим,
$$\begin{aligned} S_1 + iS_2 &= \frac{(\cos x + i\sin x) \cdot 2\sin\frac{nx}{2}\left[\cos\left(\frac{nx}{2} + \frac\pi2\right) + i\sin\left(\frac{nx}{2} + \frac\pi2\right)\right]}{2\sin\frac x2\left[\cos\left(\frac x2 + \frac\pi2\right) + i\sin\left(\frac x2 + \frac\pi2\right)\right]} \\ &= \frac{\sin\frac{nx}{2}}{\sin\frac x2}\left[\cos\left(\frac{nx}{2} + \frac\pi2 + x - \frac x2 - \frac\pi2\right) + i\sin\left(\frac{nx}{2} + \frac\pi2 + x - \frac x2 - \frac\pi2\right)\right] \\ &= \frac{\sin\frac{nx}{2}}{\sin\frac x2}\left[\cos\frac{(n+1)x}{2} + i\sin\frac{(n+1)x}{2}\right]. \end{aligned}$$
Като сравним реалните и имагинерните части на двете страни, получаваме търсените равенства. Задачата може да бъде решена и с индукция по $n$. $\square$
