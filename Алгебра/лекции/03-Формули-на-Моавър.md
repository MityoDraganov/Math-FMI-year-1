# 03. Формули на Моавър. Корени на единицата

## Формули на Моавър

**Теорема (Формули на Моавър за степенуване и за коренуване).** Нека $z = r(\cos\varphi + i\sin\varphi)$ е комплексно число и $n \in \mathbb{N}^+$ е положително естествено число. Тогава
$$z^n = r^n\big(\cos(n\varphi) + i\sin(n\varphi)\big)$$
и
$$\sqrt[n]{z} = \sqrt[n]{r}\left(\cos\frac{\varphi + 2k\pi}{n} + i\sin\frac{\varphi + 2k\pi}{n}\right), \qquad k = 0, 1, \dots, n - 1.$$

*Доказателство.* Първата формула следва по индукция по $n$ от формулата за произведение в тригонометричен вид ([[02-Тригонометричен-вид]]): при $n = 1$ е вярна, а ако $z^n = r^n(\cos n\varphi + i\sin n\varphi)$, то
$$z^{n+1} = z^n z = r^{n+1}\big(\cos(n\varphi + \varphi) + i\sin(n\varphi + \varphi)\big) = r^{n+1}\big(\cos(n+1)\varphi + i\sin(n+1)\varphi\big).$$
За втората: нека $w = \rho(\cos\psi + i\sin\psi)$ и $w^n = z$. По първата формула $\rho^n(\cos n\psi + i\sin n\psi) = r(\cos\varphi + i\sin\varphi)$, следователно $\rho^n = r$ и $n\psi = \varphi + 2m\pi$, $m \in \mathbb{Z}$, т.е. $\rho = \sqrt[n]{r}$ и $\psi = \frac{\varphi + 2m\pi}{n}$. При $m = qn + k$, $0 \leq k \leq n - 1$ ([[Делимост и остатъци]]), $\psi = \frac{\varphi + 2k\pi}{n} + 2q\pi$, т.е. $w$ е някое от числата с $k = 0, 1, \dots, n - 1$. Тези $n$ числа са различни, защото аргументите им се различават с по-малко от $2\pi$, и всяко от тях на степен $n$ дава $z$. $\square$

**Забележка.** При $z \neq 0$ уравнението $w^n = z$ има точно $n$ различни решения.

## Корени на единицата

Корените на уравнението $z^n = 1$, намерени чрез формулите на Моавър, се наричат $n$-ти корени на единицата.

**Дефиниция.** Решенията на $z^n = 1$, $z = r(\cos\varphi + i\sin\varphi)$, т.е. стойностите на $\sqrt[n]{1}$ в $\mathbb{C}$, са
$$\omega_k = \cos\frac{2k\pi}{n} + i\sin\frac{2k\pi}{n}, \qquad k = 0, 1, \dots, n - 1,$$
и се наричат **$n$-ти корени на единицата**.

$$\omega_0 = 1 = \cos 0 + i\sin 0, \qquad \omega_1 = \cos\frac{2\pi}{n} + i\sin\frac{2\pi}{n}, \qquad \omega_k = \omega_1^k.$$

**Твърдение.** $n$-тите корени на единицата са върховете на вписан в единичната окръжност правилен $n$-ъгълник ([[Разстояние между точки и окръжност]]).

*Доказателство.* $|\omega_k| = 1$, следователно всички $\omega_k$ лежат на единичната окръжност. Аргументите им $0, \frac{2\pi}{n}, \dots, \frac{2(n-1)\pi}{n}$ се различават последователно с $\frac{2\pi}{n}$, т.е. точките делят окръжността на $n$ равни дъги, а хордите между съседни точки са равни. $\square$
