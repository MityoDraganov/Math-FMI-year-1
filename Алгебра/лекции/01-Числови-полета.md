# 01. Числови полета. Комплексни числа

## Числови множества

Основните числови множества означаваме с
$$\mathbb{N} \subseteq \mathbb{Z} \subseteq \mathbb{Q} \subseteq \mathbb{R} \subseteq \mathbb{C}.$$
([[Множества и символи]])

Нека $F$ е непразно множество от числа (елементи). Имаме критерий за $a = b$, $a, b \in F$.

## Аксиоми

**Дефиниция.** Дефинираме бинарна операция „$+$“ (събиране): $\forall a, b \in F \Rightarrow a + b = c \in F$, като са в сила следните аксиоми:

- **A1)** асоциативен закон на „$+$“: $\forall a, b, c \in F:\ (a + b) + c = a + (b + c)$.

$(F, +, \text{A1})$ е **полугрупа**.

- **A2)** $\exists$ неутрален елемент (нула) $0 \in F$: $\forall a \in F:\ a + 0 = 0 + a = a$.
- **A3)** $\forall a \in F\ \exists$ противоположен на $a$ елемент $(-a) \in F$: $a + (-a) = (-a) + a = 0$.

$(F, +, \text{A1–A3})$ е **група**.

- **A4)** комутативен закон на „$+$“: $\forall a, b \in F:\ a + b = b + a$.

$(F, +, \text{A1–A4})$ е **абелева (комутативна) група**.

**Забележка.** Относно „$+$“: $\mathbb{N}$ е полугрупа; $\mathbb{Z}$, $\mathbb{Q}$, $\mathbb{R}$, $\mathbb{C}$ са абелеви групи.

**Дефиниция.** Дефинираме бинарна операция „$\cdot$“: $\forall a, b \in F \Rightarrow a \cdot b \in F$.

- **A5)** асоциативен закон на „$\cdot$“: $\forall a, b, c \in F:\ (ab)c = a(bc)$.
- **A6)** дистрибутивни закони в $F$: $\forall a, b, c \in F$:
$$a(b + c) = ab + ac, \qquad (a + b)c = ac + bc.$$

**Забележка.** Двата закона в A6 са нужни, защото без A7 не е известно дали $ab = ba$, т.е. дали $a(b+c) = (b+c)a$.

$(F, +, \cdot, \text{A1}\div\text{A6})$: $F$ е **пръстен**.

- **A7)** комутативен закон на „$\cdot$“ в $F$: $\forall a, b \in F:\ ab = ba$.

$(F, +, \cdot, \text{A1}\div\text{A6}$, не A7$)$ е **некомутативен пръстен**; $(F, +, \cdot, \text{A1}\div\text{A7})$ е **комутативен пръстен**.

- **A8)** $\exists$ неутрален елемент относно „$\cdot$“, наречен единичен (единица), $1 \in F$: $a \cdot 1 = 1 \cdot a = a$, $\forall a \in F$; $0 \neq 1$.

$(F, +, \cdot, \text{A1–A6}, \text{A8})$ е **некомутативен пръстен с 1**; $(F, +, \cdot, \text{A1}\div\text{A8})$ е **комутативен пръстен с 1**.

$\mathbb{Z}$ е комутативен пръстен с 1.

- **A9)** $\forall a \in F$, $a \neq 0$, $\exists$ обратен на $a$ елемент $a^{-1} \in F$: $aa^{-1} = a^{-1}a = 1$.

$(F, +, \cdot, \text{A1–A6}, \text{A8}, \text{A9})$ е **тяло**; $(F, +, \cdot, \text{A1}\div\text{A9})$ е **поле** (означение $\mathbb{F} = F$).

$\mathbb{Q}$ е най-малкото числово поле; $\mathbb{Q} \subseteq \mathbb{R} \subseteq \mathbb{C}$ са числови полета.

**Забележка.** Числово поле е поле $F$ с $\mathbb{Q} \subseteq F \subseteq \mathbb{C}$. В записките определението не е изписано отделно.

**Забележка (алгебричен подход).**

| | решава се | не се решава |
|---|---|---|
| $\mathbb{N}$ | $x - 7 = 0$ | $x + 7 = 0$ |
| $\mathbb{Z}$ | $x + 7 = 0$ | $3x + 7 = 0$ |
| $\mathbb{Q}$ | $3x + 7 = 0$ | $x^2 - 7 = 0$ |
| $\mathbb{R}$ | $x^2 - 7 = 0$ | $x^2 + 1 = 0$ |
| $\mathbb{C}$ | $x^2 + 1 = 0$ | |

В $\mathbb{C}$ всяко уравнение с коефициенти от $\mathbb{C}$ може да се реши.

## $\mathbb{C}$: комплексните числа

**Геометричен подход.** На $z$ съпоставяме точката $M(x, y)$ в Гаусовата равнина (оси $\mathrm{Re}$ и $\mathrm{Im}$) ([[Координатна равнина]]). В нея $\exists!\,0$, $\exists!\,1$, $0 \neq 1$. Точките $\bar z = x - iy$, $-z = -x - iy$, $-x + iy$ са симетричните на $M$ относно осите и $O$.
$$r = |z| = \sqrt{x^2 + y^2}, \qquad x = r\cos\varphi, \qquad y = r\sin\varphi,$$
$$\varphi = \arg z = \operatorname{Arg} z + 2k\pi, \qquad \operatorname{Arg} z = \varphi_0 \in [0, 2\pi) \text{ — главен аргумент на } z.$$

**Дефиниция.**
$$\mathbb{C} = \{ z = (x, y) \mid x, y \in \mathbb{R} \},$$
$$(a, b) + (c, d) := (a + c,\ b + d), \qquad (a, b)(c, d) := (ac - bd,\ ad + bc).$$
$(a, b) = (c, d) \iff a = c,\ b = d$ (в $\mathbb{R}$).

$\mathbb{R} = \{ a \in \mathbb{R} \} \cong \{ (a, 0) \mid a \in \mathbb{R} \} \subseteq \mathbb{C}$.

**Твърдение.** A1$\div$A9 са изпълнени, следователно $\mathbb{C}$ е числово поле.

*Доказателство.* Нулата е $(0, 0)$, противоположният на $(a, b)$ е $(-a, -b)$, единицата е $(1, 0)$, а при $(a, b) \neq (0, 0)$
$$(a, b)^{-1} = \left( \frac{a}{a^2 + b^2},\ \frac{-b}{a^2 + b^2} \right),$$
защото $(a, b)\left( \frac{a}{a^2+b^2}, \frac{-b}{a^2+b^2} \right) = \left( \frac{a^2 + b^2}{a^2+b^2}, \frac{-ab + ab}{a^2+b^2} \right) = (1, 0)$. Останалите аксиоми следват от съответните свойства на $\mathbb{R}$ с директна проверка по компоненти. Тъй като $\mathbb{Q} \subseteq \mathbb{R} \subseteq \mathbb{C}$, $\mathbb{C}$ е числово поле. $\square$

**Дефиниция.** $i = (0, 1)$ е **имагинерна единица**.
$$(0, 1)(0, 1) = (-1, 0) \iff i^2 = -1, \qquad (y, 0)(0, 1) = (0, y) = iy,$$
$$z = (x, y) = (x, 0) + (0, y) = x \cdot 1 + iy = x + iy.$$
$z = x + iy$ е **алгебричен вид** на к.ч. $z$:
$$\mathbb{C} = \{ z = x + iy \mid x, y \in \mathbb{R},\ i^2 = -1 \}.$$
$$z_1 + z_2 = (x_1 + iy_1) + (x_2 + iy_2) = (x_1 + x_2) + i(y_1 + y_2),$$
$$z_1 z_2 = (x_1 + iy_1)(x_2 + iy_2) = (x_1x_2 - y_1y_2) + i(x_1y_2 + x_2y_1).$$
$z_1 = z_2$ (в $\mathbb{C}$) $\iff x_1 = x_2$, $y_1 = y_2$; $x = \operatorname{Re} z$, $y = \operatorname{Im} z$.

(A1–A9 са изпълнени $\Rightarrow$ $\mathbb{C}$ е числово поле.)

Имаме $0$, $1$, $i$, $z = x + iy$. От $x, -x, y, -y \in \mathbb{R}$: $-x + iy$, $x + i(-y) = \bar z$, $-x + i(-y) = -z$ (A3).

**Дефиниция.** $z_1 + (-z_2) = z_1 - z_2$ е **разлика** на $z_1$ и $z_2$.
$$\underbrace{z + z + \dots + z}_{k\text{ пъти}} = kx + iky = k(x + iy) \text{ — } k\text{-кратен на } z \text{ елемент},$$
$$\underbrace{z \cdot z \cdots z}_{k\text{ пъти}} = z^k \text{ — } k\text{-та степен на } z.$$

**Забележка.** $(1 + i)^{2026}$ с $i^2 = -1$ и формулата на Нютон ([[02-Нютонов-бином]])
$$(a + b)^n = a^n + \sum_{k=1}^{n-1} \binom{n}{k} a^k b^{n-k} + b^n, \qquad \binom{n}{k} \in \mathbb{Z},$$
е технически сложно.

**Твърдение.** ([[Делимост и остатъци]])
$$i^n = \begin{cases} 1, & n = 4k \\ i, & n = 4k + 1 \\ -1, & n = 4k + 2 \\ -i, & n = 4k + 3. \end{cases}$$

*Доказателство.* $i^4 = (i^2)^2 = 1$, следователно $i^{4k + s} = (i^4)^k i^s = i^s$, а $i^0 = 1$, $i^1 = i$, $i^2 = -1$, $i^3 = i^2 \cdot i = -i$. $\square$

**Дефиниция.** $\bar z = x - iy$ е **комплексно спрегнатото** на $z$.

$$z \bar z = (x + iy)(x - iy) = x^2 + y^2 > 0 \quad (\text{в } \mathbb{R}) \text{ при } z \neq 0.$$

**Бел.** В записките условието е „$x \neq 0, y \neq 0$“, трябва да е „$z \neq 0$“ (т.е. $x \neq 0$ или $y \neq 0$).

**Дефиниция.** $|z| := \sqrt{x^2 + y^2}$ е **модул** на к.ч. $z$. $|z| \geq 0$ и $|z| = 0 \iff z = 0$; $|z|^2 = z\bar z$.

**Твърдение.** За $z \neq 0$
$$z^{-1} = \frac{1}{z} = \frac{1}{z} \cdot \frac{\bar z}{\bar z} = \frac{\bar z}{z \bar z} = \frac{\bar z}{|z|^2} = \frac{1}{|z|^2}\,\bar z, \qquad \frac{1}{|z|^2} \in \mathbb{R},$$
$$\frac{z_1}{z_2} = z_1 z_2^{-1} = \frac{z_1 \bar z_2}{|z_2|^2}.$$

## Тригонометричен вид на $\mathbb{C}$

**Дефиниция.** ([[Тригонометрия (единична окръжност и формули)]])
$$\mathbb{C} = \{ z = r(\cos\varphi + i\sin\varphi) \mid r = |z|,\ \varphi = \arg z \}, \qquad x = r\cos\varphi, \quad y = r\sin\varphi.$$

**Твърдение.** $z_1 = z_2 \iff |z_1| = |z_2|$ и $\operatorname{Arg} z_1 = \operatorname{Arg} z_2$ (в $\mathbb{R}$).

**Забележка.** Ако $\cos\varphi = \cos\varphi_0$ и $\sin\varphi = \sin\varphi_0$, то $\varphi = \varphi_0 + 2k\pi$ и
$$z = r(\cos\varphi_0 + i\sin\varphi_0) = r(\cos\varphi + i\sin\varphi).$$
