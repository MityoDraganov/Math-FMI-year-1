# Пример 1 (лекция 02): $n < 2^n$

**Условие.** $n < 2^n$ за всяко $n \in \mathbb{N}$.

**Какво се иска (с думи).** $\mathbb{N}$ са естествените числа $0, 1, 2, 3, \dots$, а $n \in \mathbb{N}$ се чете „$n$ е естествено число“. $2^n$ е $2$, умножено по себе си $n$ пъти ($2^0 = 1$). Трябва да покажем, че всяко естествено число е по-малко от $2^n$: например $3 < 2^3 = 8$ и $5 < 2^5 = 32$. Доказателството трябва да е за **всички** $n$, не само проверка за няколко.

*Доказателство.* С обикновена индукция по $n$; $P(n)$ е $n < 2^n$.

База: $n = 0$: $0 < 2^0 = 1$, вярно.

Стъпка: нека $n < 2^n$ за някое $n$ (индуктивна хипотеза). Тогава
$$n + 1 < 2^n + 1 \le 2^n + 2^n = 2^{n+1}.$$
В първото неравенство е използвана индуктивната хипотеза, във второто $1 \le 2^n$. Получихме $P(n+1)$, следователно $n < 2^n$ за всяко $n \in \mathbb{N}$. $\square$
