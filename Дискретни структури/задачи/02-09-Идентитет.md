# Пример 3 (лекция 02): $\mathrm{Id}_A$

**Условие.**
$$\mathrm{Id}_A = \{(a, a) \mid a \in A\} = \{(a, b) \in A^2 \mid a = b\}.$$

**Какво се иска (с думи).** $\mathrm{Id}_A$ (идентитетът в $A$) е релацията, която съдържа само двойките от елемент със самия себе си; например при $A = \{1, 2, 3\}$ тя е $\{(1,1), (2,2), (3,3)\}$. $A^2 = A \times A$ са всички наредени двойки от елементи на $A$. Трябва да се провери кои от петте свойства има тази релация (рефлексивна, антирефлексивна, симетрична, антисиметрична, транзитивна) и да се намерят домейнът $\mathrm{Dom}$ (първите елементи на двойките) и рейнджът $\mathrm{Ran}$ (вторите елементи).

*Решение.*

- рефлексивна: $a = a$ за всяко $a$;
- антирефлексивна само при $A = \emptyset$;
- симетрична: $\forall a\ \forall b\ (a = b \Longrightarrow b = a)$;
- антисиметрична: $\forall a\ \forall b\ (a = b \ \&\ b = a \Longrightarrow a = b)$;
- транзитивна: $\forall a\ \forall b\ \forall c\ (a = b \ \&\ b = c \Longrightarrow a = c)$.

$\mathrm{Dom}(\mathrm{Id}_A) = \mathrm{Ran}(\mathrm{Id}_A) = A$.
