# Съкратено умножение и изнасяне пред скоби

Почти всяка индукционна стъпка завършва с „преобразуваме израза, докато стане това, което искаме“. Нужни са ти тези няколко неща.

## Формули
- $(a+b)^2 = a^2 + 2ab + b^2$
- $(a-b)^2 = a^2 - 2ab + b^2$
- $a^2 - b^2 = (a-b)(a+b)$

**Разпознавай ги и наобратно:** $n^2 + 4n + 4 = (n+2)^2$, защото $4n = 2\cdot n\cdot 2$ и $4 = 2^2$.

## Изнасяне на общ множител
$$\frac{n^2(n+1)^2}{4} + (n+1)^3 = \frac{(n+1)^2\,\big(n^2 + 4(n+1)\big)}{4} = \frac{(n+1)^2 (n+2)^2}{4}$$
Стъпки: (1) виж какво се повтаря, тук $(n+1)^2$; (2) извади го пред скоба; (3) опрости остатъка.

## Събиране на дроби
$$\frac{n}{n+1} + \frac{1}{(n+1)(n+2)} = \frac{n(n+2) + 1}{(n+1)(n+2)} = \frac{(n+1)^2}{(n+1)(n+2)} = \frac{n+1}{n+2}$$

> **Провери се:** Разложи $x^2 - 9$. *($(x-3)(x+3)$)*
