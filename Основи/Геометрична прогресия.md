# Геометрична прогресия

Всеки член е предишният, умножен по едно и също число $q$ (частно): $1, 2, 4, 8, \dots$ ($q = 2$).

## Сумата
$$1 + q + q^2 + \dots + q^{n-1} = \frac{q^n - 1}{q - 1}, \qquad q \neq 1$$
**Защо:** нека $S$ е сумата. Тогава $qS = q + q^2 + \dots + q^n$ и $qS - S = q^n - 1$. Почти всичко се съкращава.
При $q = 1$ сумата е просто $n$.

Пример: $1 + 2 + 4 + 8 = \frac{2^4 - 1}{2 - 1} = 15$.

**Важен трик (корени на единицата):** ако $q^n = 1$, но $q \neq 1$, сумата е $\frac{1 - 1}{q - 1} = 0$.

> **Провери се:** Колко е $1 + 3 + 9 + 27$? *($\frac{3^4 - 1}{2} = 40$)*
