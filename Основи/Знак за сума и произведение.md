# Знак за сума $\sum$ и произведение $\prod$

Това е **for цикъл, написан математически**.

$$\sum_{i=\text{начало}}^{\text{край}} (\text{израз с } i)$$

```
sum = 0
for i in range(начало, край + 1):
    sum += израз(i)
```

## Примери
- $\sum_{i=1}^{5} i = 1+2+3+4+5 = 15$
- $\sum_{i=1}^{3} i^2 = 1 + 4 + 9 = 14$
- $\sum_{i=1}^{4} 2 = 2+2+2+2 = 8$ (изразът не зависи от $i$, но пак се повтаря 4 пъти)

$\prod$ е същото, но **умножаваме**: $\prod_{i=1}^{4} i = 1\cdot2\cdot3\cdot4 = 24$.

## Най-важният трик (ползва се в индукцията)
Отделяме последния член:
$$\sum_{i=1}^{n+1} a_i = \Big(\sum_{i=1}^{n} a_i\Big) + a_{n+1}$$
С думи: сумата до $n+1$ е сумата до $n$ плюс още един член.

> **Провери се:** Колко е $\sum_{i=2}^{4} (2i - 1)$? *(3 + 5 + 7 = 15)*
