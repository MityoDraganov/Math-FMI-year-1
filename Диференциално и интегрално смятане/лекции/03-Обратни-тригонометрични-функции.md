# 03. Тригонометрични и обратни тригонометрични функции

## Радиан и тригонометрична окръжност
Ъгълът от $1$ радиан е централният ъгъл, който отсича от окръжност с радиус $r$ дъга с дължина $r$. Пълният ъгъл е $2\pi$ радиана, изправеният е $\pi$ радиана.

В тригонометричната окръжност (единична окръжност с център $O$) нека $M$ е точката, съответна на ъгъл $x$, $M_1$ и $M_2$ са проекциите ѝ върху абсцисата и ординатата, $E_1 = (1, 0)$, $E_2 = (0, 1)$, $K$ е пресечната точка на правата $OM$ с допирателната в $E_1$, а $P$ е пресечната точка на $OM$ с допирателната в $E_2$. Тогава
$$\sin x = OM_2, \quad \cos x = OM_1, \quad \operatorname{tg} x = E_1K, \quad \operatorname{cotg} x = E_2P.$$

[[Тригонометрия (единична окръжност и формули)]]

## Аргументът като лице
Лицето на сектора $OE_1M$ от единичната окръжност с централен ъгъл $x$ е $S = \frac{x}{2}$.

## Основни равенства
- $\sin 0 = 0$, $\cos 0 = 1$, $\sin\frac{\pi}{2} = 1$, $\cos\frac{\pi}{2} = 0$;
- $\sin(x + y) = \sin x \cos y + \cos x \sin y$;
- $\sin(x - y) = \sin x \cos y - \cos x \sin y$;
- $\cos(x + y) = \cos x \cos y - \sin x \sin y$;
- $\cos(x - y) = \cos x \cos y + \sin x \sin y$;
- Питагорова теорема: $\cos^2 x + \sin^2 x = 1$.

*Доказателство на картина* (за $\sin(\alpha + \beta)$ и $\cos(\alpha + \beta)$). Правоъгълен триъгълник с хипотенуза $1$ и ъгъл $\beta$ е долепен до правоъгълен триъгълник с хипотенуза $\cos\beta$ и ъгъл $\alpha$ и двата са вписани в правоъгълник. Страните на правоъгълника са $\sin(\alpha + \beta) = \sin\alpha\cos\beta + \cos\alpha\sin\beta$ и $\cos\alpha\cos\beta = \cos(\alpha + \beta) + \sin\alpha\sin\beta$.

## Тригонометрични функции
- $\sin x$: периодична с период $2\pi$, нечетна, обратима в $\left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$ (строго растяща).
- $\cos x$: периодична с период $2\pi$, четна, обратима в $[0, \pi]$ (строго намаляваща).
- $\operatorname{tg} x = \frac{\sin x}{\cos x}$: периодична с период $\pi$, нечетна, обратима в $\left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$ (строго растяща).
- $\operatorname{ctg} x = \frac{\cos x}{\sin x}$: периодична с период $\pi$, нечетна, обратима в $(0, \pi)$ (строго намаляваща).

## Основно неравенство
**Твърдение.** За всяко $x \in \left(0, \frac{\pi}{2}\right)$
$$0 < \sin x < x < \operatorname{tg} x.$$

*Доказателство.* Използваме означенията от тригонометричната окръжност. Триъгълникът $OE_1M$ се съдържа в сектора $OE_1M$, който се съдържа в триъгълника $OE_1K$. Лицата им са
$$S_{\triangle OE_1M} = \frac{OE_1 \cdot MM_1}{2} = \frac{\sin x}{2}, \qquad S_{\text{сект. } OE_1M} = \frac{x}{2}, \qquad S_{\triangle OE_1K} = \frac{OE_1 \cdot E_1K}{2} = \frac{\operatorname{tg} x}{2}.$$
Следователно $\frac{\sin x}{2} < \frac{x}{2} < \frac{\operatorname{tg} x}{2}$, а $\sin x > 0$, защото $M$ е в първи квадрант. $\square$

**Бел.** В обосновката в лекцията първото лице е $S_{\triangle OM_1M} = \frac{\sin x \cos x}{2}$; от него следва само $\sin x \cos x < x$. За $\sin x < x$ трябва триъгълникът $OE_1M$ с лице $\frac{\sin x}{2}$.

## Обратни тригонометрични функции
[[Обратна функция]]

### $\arcsin x$
Дефинирана в $[-1, 1]$, стойности $\left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$, строго растяща, нечетна.
$$\sin(\arcsin x) = x \ \text{ за } x \in [-1, 1], \qquad \arcsin(\sin x) = x \ \text{ за } x \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right].$$

![[arcsin x.png]]

Функцията $\arcsin(\sin x)$ е дефинирана навсякъде, периодична с период $2\pi$, в $\left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$ съвпада с $x$, а в $\left[\frac{\pi}{2}, \frac{3\pi}{2}\right]$ с $\pi - x$.

### $\arccos x$
Дефинирана в $[-1, 1]$, стойности $[0, \pi]$, строго намаляваща,
$$\arccos(-x) = \pi - \arccos x, \qquad \cos(\arccos x) = x \ \text{ за } x \in [-1, 1], \qquad \arccos(\cos x) = x \ \text{ за } x \in [0, \pi].$$

![[arccos x.png]]

**Връзки.**
$$\arcsin x + \arccos x = \frac{\pi}{2}, \qquad \sin(\arccos x) = \sqrt{1 - x^2}, \qquad \cos(\arcsin x) = \sqrt{1 - x^2}.$$
В правоъгълен триъгълник с хипотенуза $1$ и катети $x$ и $\sqrt{1 - x^2}$ ъгълът срещу $x$ е $\arcsin x$, а другият остър ъгъл е $\arccos x$.

### $\operatorname{arctg} x$
Дефинирана в $\mathbb{R}$, стойности $\left(-\frac{\pi}{2}, \frac{\pi}{2}\right)$, строго растяща, нечетна.
$$\operatorname{tg}(\operatorname{arctg} x) = x \ \text{ за } x \in \mathbb{R}, \qquad \operatorname{arctg}(\operatorname{tg} x) = x \ \text{ за } x \in \left(-\frac{\pi}{2}, \frac{\pi}{2}\right).$$

![[arctg x.png]]

### $\operatorname{arcctg} x$
Дефинирана в $\mathbb{R}$, стойности $(0, \pi)$, строго намаляваща, $\operatorname{arcctg}(-x) = \pi - \operatorname{arcctg} x$,
$$\operatorname{ctg}(\operatorname{arcctg} x) = x \ \text{ за } x \in \mathbb{R}, \qquad \operatorname{arcctg}(\operatorname{ctg} x) = x \ \text{ за } x \in (0, \pi).$$

![[arccotg x.png]]

**Връзки.**
$$\operatorname{arctg} x + \operatorname{arcctg} x = \frac{\pi}{2}, \qquad \operatorname{tg}(\operatorname{arcctg} x) = \frac1x, \qquad \operatorname{cotg}(\operatorname{arctg} x) = \frac1x,$$
$$\sin(\operatorname{arctg} x) = \frac{x}{\sqrt{1 + x^2}}, \qquad \cos(\operatorname{arctg} x) = \frac{1}{\sqrt{1 + x^2}}.$$
В правоъгълен триъгълник с катети $1$ и $x$ и хипотенуза $\sqrt{1 + x^2}$ ъгълът срещу $x$ е $\operatorname{arctg} x$, а другият остър ъгъл е $\operatorname{arcctg} x$.

## Доказателства
### Две важни тъждества
**Твърдение.** $\sin(2\operatorname{arctg} x) = \dfrac{2x}{1 + x^2}$ за $x \in \mathbb{R}$.

*Доказателство.*
$$\sin(2\operatorname{arctg} x) = 2\sin(\operatorname{arctg} x)\cos(\operatorname{arctg} x) = 2 \cdot \frac{x}{\sqrt{1 + x^2}} \cdot \frac{1}{\sqrt{1 + x^2}} = \frac{2x}{1 + x^2}. \qquad \square$$

**Твърдение.** $\cos(2\operatorname{arctg} x) = \dfrac{1 - x^2}{1 + x^2}$ за $x \in \mathbb{R}$.

*Доказателство.*
$$\cos(2\operatorname{arctg} x) = \cos^2(\operatorname{arctg} x) - \sin^2(\operatorname{arctg} x) = \left(\frac{1}{\sqrt{1 + x^2}}\right)^2 - \left(\frac{x}{\sqrt{1 + x^2}}\right)^2 = \frac{1 - x^2}{1 + x^2}. \qquad \square$$

### Някои от твърденията, цитирани преди
**Твърдение.** $\arcsin(\sin x) = \pi - x$ за $x \in \left[\frac{\pi}{2}, \frac{3\pi}{2}\right]$.

*Доказателство.* $x \in \left[\frac{\pi}{2}, \frac{3\pi}{2}\right] \Rightarrow \alpha = \pi - x \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$, $\beta = \arcsin(\sin x) \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$. Освен това $\sin\alpha = \sin(\pi - x) = \sin x = \sin\beta$. Тъй като $\sin$ е строго растяща (следователно инекция) в $\left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$, то $\alpha = \beta$. $\square$

**Твърдение.** $\arccos(-x) = \pi - \arccos x$.

*Доказателство.* $\arccos x \in [0, \pi] \Rightarrow \alpha = \pi - \arccos x \in [0, \pi]$, $\beta = \arccos(-x) \in [0, \pi]$. Освен това $\cos\alpha = -\cos(\arccos x) = -x = \cos\beta$. Тъй като $\cos$ е инекция в $[0, \pi]$, то $\alpha = \beta$. $\square$

**Твърдение.** $\arcsin x + \arccos x = \dfrac{\pi}{2}$ за $x \in [-1, 1]$.

*Доказателство.* $\arccos x \in [0, \pi] \Rightarrow \alpha = \frac{\pi}{2} - \arccos x \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$, $\beta = \arcsin x \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]$. Освен това $\sin\alpha = \cos(\arccos x) = x = \sin\beta$, следователно $\alpha = \beta$. $\square$

**Твърдение.** $\sin(\arccos x) = \sqrt{1 - x^2}$ за $x \in [-1, 1]$.

*Доказателство.* $\arccos x \in [0, \pi] \Rightarrow \sin(\arccos x) \ge 0$. Освен това $\sin^2(\arccos x) = 1 - \cos^2(\arccos x) = 1 - x^2$, следователно $\sin(\arccos x) = \sqrt{1 - x^2}$. $\square$

**Твърдение.** $\operatorname{tg}(\operatorname{arcctg} x) = \dfrac1x$ за $x \ne 0$.

*Доказателство.* $\operatorname{tg}(\operatorname{arcctg} x) = \dfrac{1}{\operatorname{ctg}(\operatorname{arcctg} x)} = \dfrac1x$. $\square$

**Твърдение.** $\cos(\operatorname{arctg} x) = \dfrac{1}{\sqrt{1 + x^2}}$ за $x \in \mathbb{R}$.

*Доказателство.* $\operatorname{arctg} x \in \left(-\frac{\pi}{2}, \frac{\pi}{2}\right) \Rightarrow \cos(\operatorname{arctg} x) > 0$. Освен това
$$\cos^2(\operatorname{arctg} x) = \frac{\cos^2(\operatorname{arctg} x)}{\sin^2(\operatorname{arctg} x) + \cos^2(\operatorname{arctg} x)} = \frac{1}{\operatorname{tg}^2(\operatorname{arctg} x) + 1} = \frac{1}{x^2 + 1},$$
следователно $\cos(\operatorname{arctg} x) = \dfrac{1}{\sqrt{1 + x^2}}$. $\square$
