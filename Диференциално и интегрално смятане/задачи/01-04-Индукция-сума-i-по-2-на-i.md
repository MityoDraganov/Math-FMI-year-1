# Задача 4 (тема 01)

**Условие.** Да се докаже, че за всяко цяло положително $n$
$$0\cdot2^0 + 1\cdot2^1 + 2\cdot2^2 + 3\cdot2^3 + \dots + n\cdot2^n = \sum_{i=0}^{n} i\cdot2^i = (n-1)\cdot2^{n+1} + 2.$$

**Какво се иска (с думи).** $\sum_{i=0}^{n} i\cdot2^i$ е сборът на числата $i \cdot 2^i$ за $i = 0, 1, \dots, n$ (тук $i$ започва от $0$, а $2^0 = 1$). Трябва да покажем, че при всяко цяло положително $n$ (т.е. $n = 1, 2, 3, \dots$) този сбор е равен на $(n-1)\cdot2^{n+1} + 2$. Например при $n = 2$: $0 + 2 + 8 = 10$ и $1 \cdot 2^3 + 2 = 10$.

*Решение.* Индукционна база: при $n = 1$ имаме $0\cdot2^0 + 1\cdot2^1 = 2 = (1-1)\cdot2^2 + 2$.

Индукционна хипотеза: допускаме, че $\sum_{i=0}^{n} i\cdot2^i = (n-1)\cdot2^{n+1} + 2$.

Индукционна стъпка: ще докажем твърдението за $n + 1$:
$$0\cdot2^0 + 1\cdot2^1 + \dots + n\cdot2^n + (n+1)\cdot2^{n+1} = \sum_{i=0}^{n} i\cdot2^i + (n+1)\cdot2^{n+1} = (n-1)\cdot2^{n+1} + 2 + (n+1)\cdot2^{n+1}$$
$$= 2n\cdot2^{n+1} + 2 = n\cdot2^{n+2} + 2 = \big((n+1) - 1\big)\cdot2^{(n+1)+1} + 2. \qquad \square$$
