# Задача 3 (тема 01)

**Условие.** Да се докаже, че за всяко цяло $n \ge 1$
$$\frac{1}{1\cdot2} + \frac{1}{2\cdot3} + \dots + \frac{1}{n(n+1)} = \sum_{i=1}^{n} \frac{1}{i(i+1)} = \frac{n}{n+1}.$$

**Какво се иска (с думи).** $\sum_{i=1}^{n} \frac{1}{i(i+1)}$ е сборът на дробите $\frac{1}{i(i+1)}$ за $i = 1, 2, \dots, n$, тоест $\frac{1}{1\cdot2} + \frac{1}{2\cdot3} + \dots + \frac{1}{n(n+1)}$. Трябва да покажем, че при всяко цяло $n \ge 1$ този сбор е точно $\frac{n}{n+1}$. Например при $n = 2$: $\frac12 + \frac16 = \frac23$.

*Решение.* Индукционна база: $\frac{1}{1\cdot2} = \frac{1}{1+1}$.

Индукционна хипотеза: допускаме, че $\sum_{i=1}^{n} \frac{1}{i(i+1)} = \frac{n}{n+1}$.

Индукционна стъпка: ще докажем твърдението за $n + 1$:
$$\frac{1}{1\cdot2} + \dots + \frac{1}{n(n+1)} + \frac{1}{(n+1)(n+2)} = \frac{n}{n+1} + \frac{1}{(n+1)(n+2)} = \frac{n(n+2) + 1}{(n+1)(n+2)} = \frac{n^2 + 2n + 1}{(n+1)(n+2)} = \frac{n+1}{(n+1)+1}. \qquad \square$$
